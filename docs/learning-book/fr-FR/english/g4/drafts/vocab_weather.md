## 6. Vérifions ensemble

Exercice : "It is snowing today."

La météo qui se passe en ce moment utilise le Présent Continu : is + verbe + ing.

"Snow" devient "snowing" ; "today" nous indique quand.

La phrase complète est donc : It is snowing aujourd'hui.
