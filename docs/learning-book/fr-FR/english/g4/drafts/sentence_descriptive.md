## 6. Vérifions ensemble

Exercice : "The smart boy writes nicely."

Modèle : adjectif + nom + verbe + adverbe.

"Smart" décrit le garçon (adjectif) ; "nicely" décrit comment il écrit (adverbe).

La phrase complète est donc la suivante : Le garçon intelligent écrit gentiment.
