## 6. Vérifions ensemble

Exercice : "International organizations help solve global problems."

"Organizations" est au pluriel — nous utilisons help sans s.

help + un verbe (sans "to") : aider à résoudre.

La phrase complète est donc la suivante : les organisations internationales aident à résoudre les problèmes mondiaux.
