## 6. Vérifions ensemble

Exercice : "If we protect the forests, animals will survive."

Type 1 : Si + Présent Simple, will + verbe.

"Protect" est présent ; "will survive" est le résultat futur.

La phrase complète est donc la suivante : si nous protégeons les forêts, les animaux survivront.
