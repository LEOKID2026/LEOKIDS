## 6. Vérifions ensemble

Exercice : "Researchers might find a new medicine in the coming years."

could + un verbe signifie peut-être — une possibilité, pas quelque chose de certain.

"Find" signifie découvrir ; "in the coming years" nous indique quand.

La phrase complète est donc la suivante : les chercheurs pourraient trouver un nouveau médicament dans les années à venir.
