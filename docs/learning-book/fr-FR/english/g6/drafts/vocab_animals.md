## 1. Qu’apprenons-nous ?

Aujourd’hui, nous allons revoir le vocabulaire animal avec Past Continu – une action qui se produisait dans le passé.
Les baleines nageaient quand nous les avons vues.

---

## 2. Explication simple

Passé Continu — nous utilisons was ou were avec un verbe + ing :

Les baleines nageaient quand nous les avons vues.

Les dauphins sautaient près du bateau.

## 3. Exemple

## 6. Vérifions ensemble

Exercice : "The eagles were flying over the mountains when we arrived."

Une action en cours dans le passé utilise Past Continu : nous volions.

"When we arrived" utilise Past Simple, pour une action qui s'est produite à un moment donné.

La phrase complète est donc la suivante : Les aigles survolaient les montagnes lorsque nous sommes arrivés.
