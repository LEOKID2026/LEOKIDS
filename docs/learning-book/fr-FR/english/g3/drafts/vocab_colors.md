## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre à décrire les couleurs dans une phrase.
Le ciel est bleu.

---

## 2. Explication simple

Le motif avec est :

Le ciel est bleu.

Le ciel est bleu.

La fleur est rouge.

La fleur est rouge.

## 3. Exemple

Le ciel est bleu.

Le ciel est bleu.

L'herbe est verte.
