## 6. Vérifions ensemble

Exercice : "We use the internet for lessons."

"We" — après nous, nous n'ajoutons pas de s au verbe utiliser.

"The internet" est ce que nous utilisons ; "for lessons" nous dit pourquoi.

La phrase complète est donc la suivante : Nous utilisons Internet pour les cours.
