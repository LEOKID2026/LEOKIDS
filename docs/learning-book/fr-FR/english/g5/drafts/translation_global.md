## 6. Vérifions ensemble

Exercice : "Children around the world learn Anglais."

dans le monde signifie partout dans le monde.

"Children" est au pluriel — nous utilisons learn sans s.

La phrase complète est donc la suivante : Les enfants du monde entier apprennent l’anglais.
