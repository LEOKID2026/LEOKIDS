## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre des mots courts de trois lettres.
Par exemple, le mot chat comporte trois lettres.
Lorsque nous mélangeons leurs sons, nous obtenons le mot chat.

---

## 2. Explication simple

Ce sont des mots courts de trois lettres :
chat
chapeau
asseoir
soleil
stylo
lit
Dans chaque mot, nous mélangeons les sons dans l'ordre.

---

## 3. Exemple

Dans le mot chat, on mélange les sons dans l'ordre, puis on dit chat.
Dans le mot assis, nous mélangeons les sons dans l'ordre, puis nous disons assis.

---

## 4. Résolvons ensemble

Quel mot entendons-nous lorsque nous mélangeons les sons de la plume ?
Nous mélangeons les sons dans l'ordre.
stylo.
stylo
