## 6. Vérifions ensemble

Qu'est-ce qu'une porte ?
On entend le mot porte.
Pensez : une porte est la chose par laquelle nous passons pour entrer dans une pièce.
La porte désigne la chose que nous ouvrons pour entrer ou sortir.
