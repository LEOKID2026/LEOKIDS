## 1. Qu’apprenons-nous ?

Aujourd’hui, nous allons trouver étape par étape un angle manquant dans un triangle – avec une équation et x pour l’angle inconnu.
Pas seulement « 180° moins l'addition » — mais : x + angle 1 + angle 2 = 180°.

---

## 2. Explication simple

:::diagramme-géométrique
tapez : angle_basic
:::

Dans le triangle ABC, nous étiquetons l’angle manquant x.
Équation : x + A + B = 180°
Étapes :
1.
Branchez les angles connus
2.
Ajouter les connus
3.
Résoudre : x = 180° − (A + B)
4. Vérifier : x + A + B = 180°

---

## 3. Exemple

Dans un triangle : 55°, 65° et x (manquant).
Équation : x + 55° + 65° = 180°
Étape a : 55° + 65° = 120°
Étape b : x + 120° = 180°
Étape c : x = 180° − 120° = 60°
Vérifier : 60° + 55° + 65° = 180°

---

## 4. Résolvons ensemble

Dans le triangle ABC, angle A = 55°, angle B = 65°. Trouvez l'angle C - étiquetez-le x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Étape 4 (vérifier) : 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Essaie-le tu-même

Dans un triangle : 40° et 65° — écrivez l'équation x + 40° + 65° = 180° et trouvez x.
Essaie de résoudre par tu-même.
Sur la page suivante, nous vérifierons ensemble les étapes et la réponse.

---

## 6. Vérifions ensemble

Dans un triangle : angles 40° et 65° — trouvez le troisième angle x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Étape 4 (vérifier) : 75° + 40° + 65° = 180°
x = 75°

---

## 7. Pratiquons-nous !

Ici nous trouvons un angle manquant avec une équation et une vérification.
En pratique, tu trouverez x +… = 180° — ajoutez les angles connus, résolvez x et vérifiez !
