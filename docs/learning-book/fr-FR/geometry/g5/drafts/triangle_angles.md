## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons découvrir pourquoi la somme des angles dans un triangle est de 180° et l'utiliser pour trouver un angle manquant.
Idée : si tu « découpez » les trois angles et les placez ensemble, ils forment une ligne droite (180°).

---

## 2. Explication simple

:::diagramme-géométrique
tapez : angle_basic
:::

Dans le triangle ABC :
- angle A + angle B + angle C = 180°
Pourquoi ? Les trois angles ensemble « remplissent » l’ouverture d’une ligne droite — la somme est donc toujours de 180°.
Si tu connaissez A et B, trouvez C :
C = 180° − (A + B)

---

## 3. Exemple

Dans le triangle ABC : A = 60°, B = 70°
Raisonnement : 60° + 70° = 130° — "combien reste-t-il" jusqu'à 180° ?
180° − 130° = 50° → C = 50°
Vérifie : 60° + 70° + 50° = 180° — les trois angles « ferment » une ligne droite.

---

## 4. Résolvons ensemble

Dans le triangle ABC, angle A = 60°, angle B = 70°. Qu'est-ce que l'angle C ?
Étape 1 (raisonnement) : les deux angles ensemble = 60° + 70° = 130°.
Étape 2 (manquant) : 180° − 130° = 50°
Étape 3 (vérifier) : 60° + 70° + 50° = 180°
50°

## 6. Vérifions ensemble

Dans le triangle ABC : angle A = 45°, angle B = 95° — qu'est-ce que l'angle C ?
Additionnez les deux angles connus :
45° + 95° = 140°
Combien reste-t-il de 180° ?
180° - 140° = 40°
Contrôle : 45° + 95° + 40° = 180°
AngleC = 40°

---

## 7. Pratiquons-nous !

La somme à 180° dans un triangle est une règle avec raisonnement, pas seulement une formule.
En pratique, tu trouverez un angle manquant : ajoutez, soustrayez de 180° et vérifiez que la somme est de 180° !
