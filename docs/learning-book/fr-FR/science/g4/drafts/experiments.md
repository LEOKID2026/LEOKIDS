---

## 2. Explication simple

Une bonne planification d’expériences comprend :
Question de recherche : que testons-nous ?
Prédiction (hypothèse) – que pensons-nous qu’il va se passer ?
Méthode : ce que nous faisons, quelle est la variable, qu'est-ce qui reste le même
Enregistrement — tableau ou journal
Conclusion : la prédiction correspond-elle ?
Qu’avons-nous appris ?
Expériences sécurisées uniquement – ​​avec un enseignant, pas de matériaux dangereux, pas d'appareils électriques.
Imaginez planifier avant de commencer, comme une carte avant une promenade.

---

## 3. Exemple

Une plante dans une pièce chaude pousse-t-elle plus vite qu’une plante dans une chambre froide ?
Prédiction :
Dans une pièce chaude — croissance plus rapide.
Méthode :
Deux pots identiques, même quantité d’eau et même lumière ; seule température différente (variable).
Enregistrement :
Hauteur tous les jours dans une table.
Conclusion :
D’après les chiffres, les données soutiennent-elles la prédiction ?

## 6. Vérifions ensemble

La question : planifier une expérience sûre — quelle éponge absorbe le plus d'eau : grande ou petite ?
Explication scientifique :
Dans cette expérience, la variable est la taille de l’éponge – c’est ce qui change entre les essais.
Les autres conditions restent les mêmes :
Même type d'éponge, même quantité d'eau à tester.
Hypothèse possible :
Une grande éponge contient plus d’espace et absorbe donc plus d’eau.
Méthode :
Mesurez le nombre de millilitres d’eau absorbés par chaque éponge et comparez.
Conclusion :
Si la grosse éponge a absorbé davantage, les données soutiennent l'hypothèse.
Variable — taille de l'éponge. Hypothèse : une grande éponge absorbe davantage. Conclusion — basée sur des mesures.
