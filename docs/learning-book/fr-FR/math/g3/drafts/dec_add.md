---

## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre à additionner des nombres décimaux — avec un point décimal (par exemple 2,3 + 1,4).
Important : alignez les points décimaux : partie entière sous partie entière, dixièmes sous dixièmes.

---

## 2. Explication simple

2,3 + 1,4
2 + 1 = 3 (entier)
0,3 + 0,4 = 0,7 (après le point)
2,3 + 1,4 = 3,7
Règle : ajouter comme si ça ne servait à rien, puis remettre le point au même endroit.

---

## 3. Exemple visuel / concret

4,2 + 3,5
Entier : 4 + 3 = 7
Dixièmes : 2 + 5 = 7
4,2 + 3,5 = 7,7

---

## 4. Résolvons ensemble

Calculer : 1,6 + 2,2 = ?
Entier : 1 + 2 = 3
Dixièmes : 6 + 2 = 8 → 0,8
1,6 + 2,2 = 3,8

## 6. Erreur courante : attention !

Calculer : 3,6 + 2,1
Entier : 3 + 2 = 5
Dixièmes : 6 + 1 = 7 → 0,7
3,6 + 2,1 = 5,7

---

## 7. Pratiquons-nous !

Tu savez maintenant comment additionner des nombres décimaux.
En pratique, tu trouverez des additions avec un point décimal.
Alignez les points !
