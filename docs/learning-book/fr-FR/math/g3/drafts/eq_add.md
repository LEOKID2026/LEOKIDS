## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons résoudre une équation d'addition — un problème avec un nombre manquant (__).
Nous devons trouver ce qui manque pour que l'équation soit vraie.

---

## 2. Explication simple

45 + __ = 72
Demandez : qu’ajoutons-nous à 45 pour atteindre 72 ?
72 - 45 = 27
45 + 27 = 72
Ou : pensez — 45 + 20 = 65, plus 7 de plus → 27.
Le nombre manquant est 27 — et non 72 !

---

## 3. Exemple visuel / concret

38 + __ = 65
65 − 38 = 27
38 + 27 = 65

---

## 4. Résolvons ensemble

52 + __ = 80 — quel est le nombre manquant ?
80 − 52 = 28
Vérifie : 52 + 28 = 80
Le nombre manquant est le 28.

---

## 5. Essaie-le tu-même

56 + __ = 83 — quel est le nombre manquant ?
Essaie de le résoudre par tu-même.
Sur la page suivante, nous vérifierons ensemble les étapes et la réponse.

---

## 6. Erreur courante : attention !

56 + __ = 83 — quel est le nombre manquant ?
Demandez :
Qu’ajoute-t-on à 56 pour atteindre 83 ?
83 − 56 = 27
Vérifie : 56 + 27 = 83
Le nombre manquant est 27

---

## 7. Pratiquons-nous !

Tu savez maintenant comment résoudre une équation d’addition avec un nombre manquant.
En pratique, tu trouverez __ dans les équations supplémentaires.
Cherchez ce qui manque !
