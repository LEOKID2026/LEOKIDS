---

## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons résoudre des équations d'addition avec de grands nombres, jusqu'à 1 000.
Nous devons trouver ce qui manque dans __ pour que l'équation soit vraie.

---

## 2. Explication simple

125 + __ = 380
Demandez : qu’ajoutes-tu à 125 pour atteindre 380 ?
380 - 125 = 255
125 + 255 = 380
Règle : numéro manquant = total (après =) moins le numéro que tu possédez déjà.

---

## 3. Exemple visuel / concret

240 + __ = 500
500 − 240 = 260
240 + 260 = 500

---

## 4. Résolvons ensemble

318 + __ = 600 — quel est le nombre manquant ?
600 − 318 = 282
Vérifie : 318 + 282 = 600
Le nombre manquant est 282.

---

## 5. Essaie-le tu-même

180 + __ = 460 — quel est le nombre manquant ?
Essaie de le résoudre par tu-même.
Sur la page suivante, nous vérifierons ensemble les étapes et la réponse.

---

## 6. Erreur courante : attention !

180 + __ = 460 — quel est le nombre manquant ?
Numéro manquant = total moins le numéro que tu possédez déjà.
460 - 180 = 280
Vérifie : 180 + 280 = 460
Le nombre manquant est 280

---

## 7. Pratiquons-nous !

Tu savez maintenant comment résoudre les équations d’addition avec un nombre manquant jusqu’à 1 000.
Trouvez ce qui manque : soustrayez le nombre connu du total !
