## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre ce qui se passe lorsque tu multipliez un nombre par 0.
0 en multiplication est spécial — la réponse est toujours 0.

---

## 2. Explication simple

Règle :
N'importe quel nombre × 0 = 0.
52 × 0 = 0
0 × 347 = 0
Pourquoi ?
Multiplier par 0 signifie « zéro groupe » ou « zéro fois ».
Il n'y a rien, la réponse est 0.
Même un grand nombre × 0 = 0 :
9 999 × 0 = 0

---

## 3. Exemple visuel / concret

125 × 0 = ?
125 × 0 = 0
0 groupes de 125 = rien = 0.
0 × 125 = 0 — même lorsque 0 vient en premier, la réponse est 0.
