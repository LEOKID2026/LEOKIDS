---

## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons résoudre les équations de soustraction avec un nombre manquant, par exemple __ − 45 = 120.
Nous devons trouver le plus grand nombre, celui dont nous soustrayons.

---

## 2. Explication simple

__ − 45 = 120
Demandez : d'un certain nombre, nous avons soustrait 45 et avons obtenu 120 – quel est le nombre ?
120 + 45 = 165
165-45 = 120
Règle : nombre manquant avant le moins = résultat + le nombre à soustraire.

---

## 3. Exemple visuel / concret

__ − 72 = 208
208 + 72 = 280
280 − 72 = 208

---

## 4. Résolvons ensemble

__ − 38 = 142 — quel est le nombre manquant ?
142 + 38 = 180
180 − 38 = 142
Le nombre manquant est 180.

---

## 5. Essaie-le tu-même

__ − 63 = 175 — quel est le nombre manquant ?
Essaie de le résoudre par tu-même.
Sur la page suivante, nous vérifierons ensemble les étapes et la réponse.

---

## 6. Erreur courante : attention !

__ − 63 = 175 — quel est le nombre manquant ?
Nombre manquant avant le moins : ajoutez le résultat et le nombre à soustraire.
175 + 63 = 238
Vérifier : 238 − 63 = 175
Le numéro manquant est 238

---

## 7. Pratiquons-nous !

Tu savez maintenant comment résoudre les équations de soustraction avec un nombre manquant jusqu'à 1 000.
Quand __ est avant le moins — ajoutez le résultat + soustrahend !
