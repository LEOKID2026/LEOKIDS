**Portée du contenu :** Ajout de 0 à un nombre. La propriété d'identité de l'addition. Aucun point négatif.

---

## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons découvrir ce qui se passe lorsque tu ajoutez 0 à un nombre.
0 est un nombre spécial — il ne change pas la réponse en plus.

---

## 2. Explication simple

Règle :
N'importe quel nombre + 0 = le même nombre.
0 n'ajoute rien — le nombre reste le même.
456 + 0 = 456
0 + 789 = 789
Pourquoi ? 0 signifie « rien à ajouter ».
Si tu avez 456 éléments et ajoutez 0, tu en avez toujours 456.
Même avec de gros chiffres, la règle est la même.

---

## 3. Exemple visuel / concret

2 350 + 0 = ?
2 350 + 0 = 2 350
0 + 2 350 = 2 350
Dans les deux cas, la réponse est la même : 2 350.

---

## 4. Résolvons ensemble

Calcule : 1 008 + 0 = ?
Ajouter 0 - rien ne change.
1 008 + 0 = 1 008
1 008

## 6. Erreur courante : attention !

Calcule : 1 789 + 0 = ?
Ajouter 0 à 0 n'ajoute rien, le nombre reste.
1 789 + 0 = 1 789
1 789

## 7. Pratiquons-nous !

Tu savez maintenant que l’ajout de 0 ne change pas la réponse.
En pratique, tu trouverez des ajouts avec 0.
Le numéro reste le même !
