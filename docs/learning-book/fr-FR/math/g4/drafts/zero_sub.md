---

## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre ce qui se passe lorsque tu soustrayez 0 d'un nombre.
0 ne « prend » rien – le nombre reste le même.

---

## 2. Explication simple

Règle :
N'importe quel nombre - 0 = le même nombre.
789 − 0 = 789
3 200 − 0 = 3 200
Pourquoi ? 0 signifie « rien à emporter ».
Si tu avez 789 choses et enlevez 0, tu en avez toujours 789.
Attention :
Ceci est différent de 789 − 789 (qui vaut 0).
Ici, tu soustrayez 0, pas le nombre lui-même.

---

## 3. Exemple visuel / concret

5 640 - 0 = ?
5 640 − 0 = 5 640
En soustrayant « rien » – 5 640 séjours.

---

## 4. Résolvons ensemble

Calcule : 2 501 − 0 = ?
Soustraire 0 - rien ne change.
2 501 − 0 = 2 501
2 501

## 6. Erreur courante : attention !

Calcule : 4 125 − 0 = ?
Soustraire 0 à 0 n'enlève rien, le nombre reste.
4 125 − 0 = 4 125
4 125

---

## 7. Pratiquons-nous !

Tu savez maintenant que soustraire 0 ne change pas la réponse.
En pratique, tu trouverez des soustractions avec 0.
Le numéro reste le même !
