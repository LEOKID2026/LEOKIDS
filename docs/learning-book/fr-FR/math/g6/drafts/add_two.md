## 1. Qu’apprenons-nous ?

Aujourd'hui, nous allons apprendre à additionner deux nombres jusqu'à 200 000.
Travaillez à partir de uns → dizaines → centaines → milliers → dix milliers → centaines de milliers, avec portage.

---

## 2. Explication simple

12 450 + 3 875 :
- les uns : 0+5=5
- dizaines : 5+7=12 → 2, porter 1
- centaines : 4+8+1=13 → 3, porter 1
- des milliers : 2+3+1=6
- dix milliers : 1+0=1
= 16 325

---

## 3. Exemple visuel / concret

48 750 + 25 680 = 74 430
Vérifie : 74 430 − 25 680 = 48 750

---

## 4. Résolvons ensemble

Calcule 48 750 + 25 680 = ?
Uns : 0 + 0 = 0
Dizaines : 5 + 8 = 13 → écrire 3, porter 1
Centaines : 7 + 6 + 1 = 14 → écrire 4, porter 1
Milliers : 8 + 5 + 1 = 14 → écrire 4, porter 1
Dix milliers : 4 + 2 + 1 = 7
48 750 + 25 680 = 74 430

## 6. Erreur courante : attention !

Calculer : 34 267 + 15 486
Les uns : 7+6=13 → 3, portez 1.
Dizaines : 6+8+1=15 → 5, portez 1.
Centaines : 2+4+1=7
Milliers : 4+5=9
Dix mille : 3+1=4
La réponse : 49 753
