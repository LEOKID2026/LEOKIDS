## 1. Qu’apprenons-nous ?

Aujourd’hui, nous allons renforcer l’ajout de décimales – deux chiffres après la virgule.
Alignez les points décimaux !

---

## 2. Explication simple

14h45 + 13h30 :
Aligner : 2,45 + 1,30 = 3,75
Les points décimaux s'alignent – un sous un.

---

## 3. Exemple visuel / concret

0.08 + 0.15 = 0.23

---

## 4. Résolvons ensemble

2,45 + 1,30 = ?
Alignez les points décimaux.
5+0=5, 4+3=7, 2+1=3
3.75.

---

## 5. Essaie-le tu-même

Calculer : 3,67 + 2,85 = ?
Essaie de le résoudre par tu-même.
Sur la page suivante, nous vérifierons ensemble les étapes et la réponse.

---

## 6. Erreur courante : attention !

Calculer : 3,67 + 2,85
Alignez les points décimaux.
Centièmes : 7+5=12 → 2, porter 1.
Dixièmes : 6+8+1=15 → 5, porter 1.
Les uns : 3+2+1=6
La réponse : 6.52

---

## 7. Pratiquons-nous !

L'ajout de décimales est nécessaire pour l'argent et les mesures.
En pratique, tu ajouterez des décimales — alignez-les toujours !
