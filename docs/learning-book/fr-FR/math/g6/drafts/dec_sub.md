## 6. Erreur courante : attention !

Calculer : 8,40 − 3,75
Centièmes : 0<5 → emprunter aux dixièmes. 10−5=5.
Dixièmes : 3 (après emprunt) < 7 → emprunter aux uns. 13−7=6.
Uns : 7 (après emprunt) − 3 = 4.
Vérifie : 4,65 + 3,75 = 8,40
La réponse : 4,65

---

## 7. Pratiquons-nous !

La soustraction de décimales nécessite un alignement minutieux.
En pratique, tu soustraireez des décimales — vérifiez avec addition !
