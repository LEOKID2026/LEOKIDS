## 1. Что мы изучаем?

Сегодня мы найдём неизвестный угол в треугольнике шаг за шагом — с уравнением и x для неизвестного угла.
Не просто «180° минус сложение» — а: x + угол 1 + угол 2 = 180°.

---

## 2. Простое объяснение

:::geometry-diagram
type: angle_basic
:::

В треугольнике ABC недостающий угол обозначаем x.
уравнение: x + A + B = 180°
Шаги:
1.
Plug in the known angles
2.
Add the known ones
3.
Реши: x = 180° − (A + B)
4. Проверка: x + A + B = 180°

---

## 3. Пример

В треугольнике: 55°, 65°, и x (missing).
уравнение: x + 55° + 65° = 180°
шаг a: 55° + 65° = 120°
шаг b: x + 120° = 180°
шаг c: x = 180° − 120° = 60°
Проверка: 60° + 55° + 65° = 180°

---

## 4. Решим вместе

В треугольнике ABC угол A = 55°, угол B = 65°. Найди угол C — обозначь его x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Шаг 4 (проверка): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Попробуй сам

В треугольнике: 40° и 65° — запиши уравнение x + 40° + 65° = 180° и найди x.
Попробуй решить сам.
На следующей странице мы вместе проверим шаги и ответ.

---

## 6. Проверим вместе

В треугольнике: углы 40° и 65° — найди третий угол x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Шаг 4 (проверка): 75° + 40° + 65° = 180°
x = 75°

---

## 7. Давай попрактикуемся!

Здесь мы находим недостающий угол с уравнением и проверкой.
В практике ты встретишь x +… = 180° — сложи известные углы, найди x и проверь!
