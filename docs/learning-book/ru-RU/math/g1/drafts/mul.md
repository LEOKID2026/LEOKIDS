---

## 2. Простое объяснение

3 × 2 = три группы по 2
= 2 + 2 + 2 = 6
× означает "групп по".
Можно также сказать «раз».
3 × 2 = 6 — три раза по два.
Здесь мы используем небольшое умножение: группы до 5, ответы до 20.

---

## 3. Наглядный пример

3 × 2 — три группы по 2 звезды:
повторное сложение: 2 + 2 + 2 = 6
умножение: 3 × 2 = 6
Пример с наклейками:
4 группы, по 3 наклеек в каждой → 3 + 3 + 3 + 3 = 12
→ 4 × 3 = 12

## 6. Частая ошибка — будь внимателен!

3 × 3 = ?
3 × 3 = три группы по 3.
повторное сложение: 3 + 3 + 3.
3 + 3 = 6, тогда 6 + 3 = 9.
3 × 3 = 9
