## 6. Частая ошибка — будь внимателен!

Вычисли: 8.40 − 3.75
Сотые: 0<5 → займи у десятых. 10−5=5.
Десятые: 3 (после займа) < 7 → займи у единиц. 13−7=6.
Единицы: 7 (после займа) − 3 = 4.
Проверка: 4.65 + 3.75 = 8.40
Ответ: 4.65
