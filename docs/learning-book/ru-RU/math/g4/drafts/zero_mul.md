## 1. Что мы изучаем?

Сегодня мы узнаем, что происходит, когда число умножают на 0.
0 в умножении особенный — ответ всегда 0.

---

## 2. Простое объяснение

Правило:
Any число × 0 = 0.
52 × 0 = 0
0 × 347 = 0
Why?
Умножение на 0 значит «ноль групп» или «ноль раз».
Ничего нет — ответ 0.
Даже большое число × 0 = 0:
9,999 × 0 = 0

---

## 3. Наглядный пример

125 × 0 = ?
125 × 0 = 0
0 групп по 125 = ничего = 0.
0 × 125 = 0 — даже когда 0 стоит первым, ответ 0.
