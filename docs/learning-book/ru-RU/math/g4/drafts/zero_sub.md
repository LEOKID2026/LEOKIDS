## 1. Что мы изучаем?

Сегодня мы узнаем, что происходит, когда из числа вычитают 0.
0 ничего не «забирает» — число остаётся тем же.

---

## 2. Простое объяснение

Правило:
Любое число − 0 = то же число.
789 − 0 = 789
3,200 − 0 = 3,200
Почему? 0 значит «нечего убирать».
Если у тебя 789 предметов и ты убираешь 0 — у тебя всё ещё 789.
Будь внимателен:
Это отличается от 789 − 789 (что равно 0).
Здесь ты вычитаешь 0, а не само число.

---

## 3. Наглядный пример

5,640 − 0 = ?
5,640 − 0 = 5,640
Вычитание «ничего» — 5640 остаётся.
