## 1. Что мы изучаем?

Сегодня мы узнаем, что происходит, когда к числу прибавляют 0.
0 — особое число: в сложении оно не меняет ответ.

---

## 2. Простое объяснение

Правило:
Любое число + 0 = то же число.
0 ничего не прибавляет — число остаётся тем же.
456 + 0 = 456
0 + 789 = 789
Почему? 0 значит «нечего прибавлять».
Если у тебя 456 предметов и ты прибавляешь 0 — у тебя всё ещё 456.
Даже с большими числами — правило то же.

---

## 3. Наглядный пример

2,350 + 0 = ?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
В обоих случаях ответ один и тот же — 2350.

---

1,008 + 0 = 1,008
