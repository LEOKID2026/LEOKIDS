## 1. Cosa stiamo imparando?

Today we'll imparare a estimate un addizione risposta — non calculate exactly, but get close.
≈ means su, close a.

---

## 2. Spiegazione semplice

3,487 + 2,512 ≈?
Round a nearest thousand:
3,487 ≈ 3,500
2,512 ≈ 2,500
3,500 + 2,500 = 6,000
3,487 + 2,512 ≈ 6,000

---

## 3. Esempio visuale / concreto

1,298 + 4,703 ≈?
1,298 ≈ 1,300; 4,703 ≈ 4,700
1,300 + 4,700 = 6,000

---

## 4. Risolviamo insieme

3,487 + 2,512 ≈?
3,487 ≈ 3,500; 2,512 ≈ 2,500
3,500 + 2,500 = 6,000
≈ 6,000
