## 1. Cosa stiamo imparando?

Today we'll imparare cosa happens quando tu sottrarre 0 da un numero.
0 doesn't "prendere" anything — numero stays stesso.

---

## 2. Spiegazione semplice

Rule:
Any numero − 0 = stesso numero.
789 − 0 = 789
3,200 − 0 = 3,200
Perché? 0 means "nothing a prendere away."
Se tu avere 789 things e prendere away 0 — tu still avere 789.
Watch out:
Questo è diverso da 789 − 789 (quale è 0).
Qui tu sottrarre 0, non numero itself.

---

## 3. Esempio visuale / concreto

5,640 − 0 =?
5,640 − 0 = 5,640
Subtracting "nothing" — 5,640 stays.

Subtracting 0 — nothing changes.
