---

## 1. Cosa stiamo imparando?

Today we'll imparare sequences con big jumps — non just +1 o +5, but jumps come +50 o +100.
Trovare rule e keep going — up a 10,000.

---

## 2. Spiegazione semplice

UN sequence = numeri in un row following un rule.
Fixed jump: ogni passaggio tu addizionare (o sottrarre) stesso numero.
100, 150, 200, 250, …
- 150 − 100 = 50
- 200 − 150 = 50
- jump: +50 ogni time
poi numero: 250 + 50 = 300

---

## 3. Esempio visuale / concreto

3,250, 3,300, 3,350, 3,400,?
3,300 − 3,250 = 50
3,350 − 3,300 = 50
3,400 − 3,350 = 50
Jump: +50
3,400 + 50 = 3,450
Risposta: 3,450

---

## 4. Risolviamo insieme

Continue: 2,800, 2,850, 2,900, 2,950,?
2,850 − 2,800 = 50 jump è +50.
2,950 + 50 = 3,000
3,000
