## 1. Cosa stiamo imparando?

Today we'll imparare cosa happens quando tu moltiplicare un numero by 0.
0 in moltiplicazione è special — risposta è always 0.

---

## 2. Spiegazione semplice

Rule:
Any numero × 0 = 0.
52 × 0 = 0
0 × 347 = 0
Perché?
Multiplying by 0 means "zero gruppi" o "zero times."
There's nothing — risposta è 0.
Even un big numero × 0 = 0:
9,999 × 0 = 0

---

## 3. Esempio visuale / concreto

125 × 0 =?
125 × 0 = 0
0 gruppi di 125 = nothing = 0.
0 × 125 = 0 — even quando 0 comes prima, risposta è 0.
