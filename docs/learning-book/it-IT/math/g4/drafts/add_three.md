## 1. Cosa stiamo imparando?

In questo section we'll imparare a addizionare tre numeri — uno dopo another o in friendly gruppi.
Per esempio: 350 + 120 + 80.

---

## 2. Spiegazione semplice

Ways a addizionare tre numeri:
Uno dopo another: (350 + 120) + 80
Friendly pair prima: 350 + (120 + 80) — quando 120 + 80 = 200
Rounding: 398 + 102 + 50 → (398 + 102) + 50 = 500 + 50
Important: addizionare tutti tre numeri — don't stop dopo due!
350 + 120 + 80:
350 + 120 = 470
470 + 80 = 550

---

## 3. Esempio visuale / concreto

2,450 + 350 + 1,200
2,450 + 1,200 = 3,650 ( due bigger numeri prima)
3,650 + 350 = 4,000
2,450 + 350 + 1,200 = 4,000

---

## 4. Risolviamo insieme

Work out: 820 + 180 + 500 =?
820 + 180 = 1,000 (friendly pair — ends in 0).
1,000 + 500 = 1,500
820 + 180 + 500 = 1,500

## 6. Errore comune — attenzione!

Work out: 450 + 120 + 80 =?
Look per un friendly pair: 120 + 80 = 200
450 + 200 = 650
450 + 120 + 80 = 650
