## 1. Cosa stiamo imparando?

Today we'll trovare neighbors in big numeri — up a 10,000.
±1 even quando crossing un thousand — per esempio 1,999 → 2,000 → 2,001.

---

## 2. Spiegazione semplice

Neighbor prima = −1
Neighbor dopo = +1
2,450:
- prima: 2,449
- dopo: 2,451
Crossing un thousand:
- 1,999 → dopo = 2,000
- 2,000 → prima = 1,999
Place value: quando tu cross un thousand, tutti digits può change — but jump è still 1.

---

## 3. Esempio visuale / concreto

3,628:
3,628 − 1 = 3,627
3,628 + 1 = 3,629
2,999 → 3,000: neighbor dopo 2,999 = 3,000 — crossing un thousand, still just +1.
3,626 — 3,627 — [3,628] — 3,629 — 3,630

---

## 4. Risolviamo insieme

Cosa sono neighbors di 2,450?
Prima = 2,450 − 1 = 2,449
Dopo = 2,450 + 1 = 2,451
2,449 e 2,451
