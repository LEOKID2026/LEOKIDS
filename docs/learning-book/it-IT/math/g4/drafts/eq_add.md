## 1. Cosa stiamo imparando?

Today we'll risolvere addizione equations con big numeri — up a 1,000.
Noi need a trovare what's missing in __ so equation è true.

---

## 2. Spiegazione semplice

125 + __ = 380
Ask: cosa fare tu addizionare a 125 a reach 380?
380 − 125 = 255
125 + 255 = 380
Rule: missing numero = totale (dopo =) minus numero tu already avere.

---

## 3. Esempio visuale / concreto

240 + __ = 500
500 − 240 = 260
240 + 260 = 500

---

## 4. Risolviamo insieme

318 + __ = 600 — cosa è missing numero?
600 − 318 = 282
Controllare: 318 + 282 = 600
missing numero è 282.

## 6. Errore comune — attenzione!

180 + __ = 460 — cosa è missing numero?

missing numero è 280
