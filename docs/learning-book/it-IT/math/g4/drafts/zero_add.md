## 1. Cosa stiamo imparando?

Today we'll imparare cosa happens quando tu addizionare 0 a un numero.
0 è un special numero — esso doesn't change risposta in addizione.

---

## 2. Spiegazione semplice

Rule:
Any numero + 0 = stesso numero.
0 doesn't addizionare anything — numero stays stesso.
456 + 0 = 456
0 + 789 = 789
Perché? 0 means "nothing a addizionare."
Se tu avere 456 things e addizionare 0 — tu still avere 456.
Even con big numeri — rule è stesso.

---

## 3. Esempio visuale / concreto

2,350 + 0 =?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
In both cases risposta è stesso — 2,350.

## 4. Risolviamo insieme

Work out: 1,008 + 0 =?
Adding 0 — nothing changes.
1,008 + 0 = 1,008
