**Ambito del contenuto:** Addition con **decimale point** — uno digit dopo point. No due decimale digits.

---

## 1. Cosa stiamo imparando?

Oggi impariamo a addizionare decimale numeri — con un decimale point (per esempio 2.3 + 1.4).
Important: line up decimale points — intero parte under intero parte, tenths under tenths.

---

## 2. Spiegazione semplice

2.3 + 1.4
2 + 1 = 3 (intero)
0.3 + 0.4 = 0.7 (dopo point)
2.3 + 1.4 = 3.7
Rule: addizionare as se there's no point, allora mettere point in stesso place.

---

## 3. Esempio visuale / concreto

4.2 + 3.5
Intero: 4 + 3 = 7
Tenths: 2 + 5 = 7
4.2 + 3.5 = 7.7

---

## 4. Risolviamo insieme

Calculate: 1.6 + 2.2 =?
Intero: 1 + 2 = 3
Tenths: 6 + 2 = 8 → 0.8
1.6 + 2.2 = 3.8
