## 1. Cosa stiamo imparando?

Today noi risolvere un addizione equation — un problem con un missing numero (__).
Noi need a trovare what's missing so equation è true.

---

## 2. Spiegazione semplice

45 + __ = 72
Ask: cosa fare noi addizionare a 45 a reach 72?
72 − 45 = 27
45 + 27 = 72
O: think — 45 + 20 = 65, plus 7 più → 27.
missing numero è 27 — non 72!

---

## 3. Esempio visuale / concreto

38 + __ = 65
65 − 38 = 27
38 + 27 = 65

---

## 4. Risolviamo insieme

52 + __ = 80 — cosa è missing numero?
80 − 52 = 28
Controllare: 52 + 28 = 80
missing numero è 28.
