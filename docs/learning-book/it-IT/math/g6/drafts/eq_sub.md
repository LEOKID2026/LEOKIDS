## 2. Spiegazione semplice

200,000 −? = 175,000 — missing numero in middle:
? = minuend − result = 200,000 − 175,000
Rule: quando __ comes dopo minus sign — sottrarre result da minuend.

## 3. Esempio visuale / concreto
