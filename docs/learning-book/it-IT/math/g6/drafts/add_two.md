## 1. Cosa stiamo imparando?

Oggi impariamo a addizionare due numeri up a 200,000.
Work da ones → tens → hundreds → thousands → dieci thousands → hundred thousands, con carrying.

---

## 2. Spiegazione semplice

12,450 + 3,875:
- ones: 0+5=5
- tens: 5+7=12 → 2, carry 1
- hundreds: 4+8+1=13 → 3, carry 1
- thousands: 2+3+1=6
- dieci thousands: 1+0=1
= 16,325

---

## 3. Esempio visuale / concreto

48,750 + 25,680 = 74,430
Controllare: 74,430 − 25,680 = 48,750

---

## 4. Risolviamo insieme

Calculate 48,750 + 25,680 =?
Ones: 0 + 0 = 0
Tens: 5 + 8 = 13 → scrivere 3, carry 1
Hundreds: 7 + 6 + 1 = 14 → scrivere 4, carry 1
Thousands: 8 + 5 + 1 = 14 → scrivere 4, carry 1
Dieci thousands: 4 + 2 + 1 = 7
48,750 + 25,680 = 74,430
