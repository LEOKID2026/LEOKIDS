## 6. Errore comune — attenzione!

Calculate: 8.40 − 3.75
Hundredths: 0<5 → borrow da tenths. 10−5=5.
Tenths: 3 (dopo borrowing) < 7 → borrow da ones. 13−7=6.
Ones: 7 (dopo borrowing) − 3 = 4.
Controllare: 4.65 + 3.75 = 8.40
risposta: 4.65
