## 1. Cosa stiamo imparando?

Today noi strengthen place value con big numeri — up a 200,000.
Noi identify hundred thousands, dieci thousands, thousands, hundreds, tens, e ones.

---

## 2. Spiegazione semplice

125,480 = uno hundred thousand + 2 dieci thousands + 5 thousands + 4 hundreds + 8 tens + 0 ones
Quando tu leggere un big numero — start da left ( largest digit).
48,650 — digit 4 è in dieci thousands place (40,000).

---

## 3. Esempio visuale / concreto

73,205:
- 7 in dieci thousands place → 70,000
- 3 in thousands place → 3,000
- 2 in hundreds place → 200
- 0 in tens place
- 5 in ones place
70,000 + 3,000 + 200 + 5 = 73,205

---

## 4. Risolviamo insieme

In 125,480 — cosa è value di digit 5?
digit 5 è in thousands place.
Valore = 5 × 1,000 = 5,000.
digit 5 è worth 5,000.

## 6. Errore comune — attenzione!
