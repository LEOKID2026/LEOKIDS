## 2. Spiegazione semplice

Physical change — materiale stays stesso materiale, solo figura changes.
Esempio: ice melts a acqua — still acqua.
Chemical change — un new materiale è formed.
Esempio: un baked egg — fa non return a un liquid egg.
Electricity (concepts solo):
- Conductor — un materiale che allows electricity a pass through (metallo come iron, copper)
- Insulator — un materiale che makes esso hard per electricity a pass (plastic, rubber)
UN metallo coin — conductor:
Electricity può pass through esso.
UN plastic pen — insulator:
Electricity almost fa non pass through esso.
Lì sono no instructions per wiring circuits qui — solo understanding.

## 6. Controlliamo insieme

question: un rubber balloon, un metallo spoon, un wool string — quale conducts electricity? Quale è un insulator?
Scientific explanation:
UN conductor è un materiale che allows electricity a flow through esso easily — usually metals.
Un insulator è un materiale che makes esso very hard per electricity a pass — come rubber, plastic, wool, legno.
UN metallo spoon è made di metallo (come stainless steel) — un good conductor.
UN rubber balloon è made di rubber — un excellent natural insulator.
UN wool string è made di natural fibers — anche un insulator; electricity fa non pass easily.
Metallo spoon — conductor. Rubber balloon — insulator. Wool string — insulator.
