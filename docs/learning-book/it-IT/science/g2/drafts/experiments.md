## 1. Cosa stiamo imparando?

Today in science noi imparare come a investigate come scientists — con observation, comparison, e uno variable.

---

## 2. Spiegazione semplice

Scientific investigation starts simply:
Observation — noi look e describe (cosa è happening?)
Comparison — noi confrontare due situations (cosa è diverso?)
Uno variable — change solo uno thing; everything else stays stesso (un fair test)
Safe esempio:
Due identical pots — uno gets luce, uno gets darkness.
Solo luce changes — everything else è stesso.
Con un insegnante solo.
No fire, no chemicals, no electricity.

---

## 3. Esempio

Fa un pianta by window grow taller?
Observation:
Misurare altezza every day.
Comparison:
Pot by window versus pot in un dark corner.
Variable:
Location (luce).
Stesso:
Stesso amount di acqua, stesso pot, stesso seed.
Scrivere down cosa tu see — senza guessing.

---

## 4. Risolviamo insieme

Perché change solo uno thing in un test?
Se tu change both acqua e luce — tu fare non know cosa made difference.
Uno variable — un clear result.
So noi know cosa caused change

## 6. Controlliamo insieme

question era:
Cosa essere variable in un test di un pianta by un window versus un pianta in un dark corner?
In un fair test tu change solo uno thing — che è variable.
Qui:
location (by un window con luce versus un dark corner) è solo thing che changes.
Everything else stays stesso:
Stesso pot, stesso acqua, stesso seed.
risposta: variable è amount di luce ( plant's location).
