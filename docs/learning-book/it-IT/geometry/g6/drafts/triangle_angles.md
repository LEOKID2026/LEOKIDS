## 1. Cosa stiamo imparando?

Today noi trovare un missing angolo in un triangolo passaggio by passaggio — con un equation e x per unknown angolo.
Non just "180° minus addizione" — but: x + angolo 1 + angolo 2 = 180°.

---

## 2. Spiegazione semplice

:::geometry-diagram
type: angle_basic
:::

In triangolo ABC, noi label missing angolo x.
Equation: x + UN + B = 180°
Passaggi:
1.
Plug in known angoli
2.
Addizionare known ones
3.
Risolvere: x = 180° − (UN + B)
4. Controllare: x + UN + B = 180°

---

## 3. Esempio

In un triangolo: 55°, 65°, e x (missing).
Equation: x + 55° + 65° = 180°
Passaggio un: 55° + 65° = 120°
Passaggio b: x + 120° = 180°
Passaggio c: x = 180° − 120° = 60°
Controllare: 60° + 55° + 65° = 180°

---

## 4. Risolviamo insieme

In triangolo ABC angolo UN = 55°, angolo B = 65°. Trovare angolo C — label esso x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Passaggio 4 (controllare): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Prova tu

In un triangolo: 40° e 65° — scrivere equation x + 40° + 65° = 180° e trovare x.
Try a risolvere by yourself.
Nella pagina successiva controlleremo insieme i passaggi e la risposta.

---

## 6. Controlliamo insieme

In un triangolo: angoli 40° e 65° — trovare terzo angolo x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Passaggio 4 (controllare): 75° + 40° + 65° = 180°
x = 75°

---
