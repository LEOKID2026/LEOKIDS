## 1. Cosa stiamo imparando?

Today we'll imparare area di un parallelogram.
Area = base × altezza.
altezza — perpendicular distance a base (non slanted lato!).

---

## 2. Spiegazione semplice

:::geometry-diagram
type: parallelogram_area
:::

In un parallelogram:
- base — lato noi scegliere (per esempio 8 cm)
- altezza — perpendicular segment da base a parallel lato (5 cm)
Area = base × altezza
Don't use slanted lato — solo altezza.

---

## 3. Esempio

Base 8 cm, altezza 5 cm:
8 × 5 = 40 cm²
