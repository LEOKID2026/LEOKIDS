## 1. Cosa stiamo imparando?

Today we'll classify quadrilaterals — parallelogram, trapezoid, rettangolo, quadrato.
Qui — inclusion relationships: quale figura "fits inside" quale?

---

## 2. Spiegazione semplice

:::geometry-diagram
type: quadrilateral_parts
:::

Parallelogram ← rettangolo ← quadrato (inclusion chain)
Trapezoid — separate: solo uno pair parallel (non 2 pairs).
Parallelogram — 2 pairs di parallel lati.
Trapezoid — 1 pair ( bases).
Rectangle — 2 pairs + 90°.
Square — 2 pairs + uguale lati.

---

## 3. Esempio

UN house roof — trapezoid figura: parallel bases, non-parallel lato edges.
→ Trapezoid — non un parallelogram (solo uno pair).
UN playground — un "tilted" parallelogram: 2 pairs di parallel lati.

---

## 4. Risolviamo insieme

UN quadrilateral con solo parallel bases — trapezoid o parallelogram?
Solo uno parallel pair → trapezoid.
Trapezoid

## 6. Controlliamo insieme

Quadrilateral PQRS — solo PQ ∥ SR.
Trapezoid o parallelogram?
Contare parallel pairs:
Solo uno pair — PQ ∥ SR.
Uno parallel pair → trapezoid
(UN parallelogram = 2 pairs; qui solo 1.)
Trapezoid
