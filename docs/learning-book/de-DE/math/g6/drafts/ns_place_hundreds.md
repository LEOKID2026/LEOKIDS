## 2. Einfache Erklärung

125,480 = one hundred thousand + 2 ten thousands + 5 thousands + 4 hundreds + 8 tens + 0 ones
Wenn du eine große Zahl liest — beginne von links (die größte Ziffer).
48.650 — digit 4 ist in ten thousands place (40.000).

---

## 3. Anschauliches / konkretes Beispiel

73,205:
- 7 in ten thousands place → 70,000
- 3 in thousands place → 3,000
- 2 in hundreds place → 200
- 0 in tens place
- 5 in ones place
70,000 + 3,000 + 200 + 5 = 73,205

---

## 4. Lass uns gemeinsam lösen

In 125.480 — was ist der Wert der Ziffer 5?
Digit 5 ist in thousands place.
Value = 5 × 1,000 = 5,000.
Digit 5 ist worth 5.000.

---

## 6. Häufiger Fehler — Achtung!

In 125.480 — was ist der Wert der Ziffer 2?
Place order: 1 = hundred thousands, 2 = ten thousands, 5 = thousands, 4 = hundreds, 8 = tens, 0 = ones.
Digit 2 ist in ten thousands place.
Value = 2 × 10,000 = 20,000.
Answer: 20,000
