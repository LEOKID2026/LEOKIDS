---

## 6. Häufiger Fehler — Achtung!

Berechnen: 8.40 − 3.75
Hundertstel: 0<5 → borgen von den Zehnteln. 10−5=5.
Tenths: 3 (nach dem Ausleihen) < 7 → borrow von Einer. 13−7=6.
Einer: 7 (nach dem Ausleihen) − 3 = 4.
Prüfen: 4.65 + 3.75 = 8.40
Answer: 4.65
