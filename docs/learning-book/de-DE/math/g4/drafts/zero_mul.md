---

## 1. Was lernen wir?

Heute lernen wir, was passiert, wenn du eine Zahl mit 0 multiplizierst.
0 in multiplication ist special — die Antwort ist immer 0.

---

## 2. Einfache Erklärung

Regel:
Jede Zahl × 0 = 0.
52 × 0 = 0
0 × 347 = 0
Warum?
Multiplizieren mit 0 bedeutet „null Gruppen“ oder „null mal“.
Re's nichthing — answer ist 0.
Sogar eine große Zahl × 0 = 0:
9,999 × 0 = 0

---

## 3. Anschauliches / konkretes Beispiel

125 × 0 = ?
125 × 0 = 0
0 Gruppen von 125 = nothing = 0.
0 × 125 = 0 — auch wenn 0 zuerst kommt, ist das Ergebnis 0.
