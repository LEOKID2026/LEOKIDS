**Inhaltsumfang:** 0 zu einer Zahl addieren. Die Identitätseigenschaft der Addition. Keine negativen Zahlen.

---

## 1. Was lernen wir?

Heute lernen wir, was passiert, wenn du 0 zu einer Zahl addierst.
0 ist eine besondere Zahl — sie ändert das Ergebnis bei der Addition nicht.

---

## 2. Einfache Erklärung

Regel:
Jede Zahl + 0 = dieselbe Zahl.
0 addiert nichts — die Zahl bleibt gleich.
456 + 0 = 456
0 + 789 = 789
Warum? 0 bedeutet „nichts zu addieren“.
Wenn du 456 Dinge hast und 0 addierst — hast du immer noch 456.
Auch bei großen Zahlen — die Regel ist dieselbe.

---

## 3. Anschauliches / konkretes Beispiel

2,350 + 0 = ?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
In beiden Fällen ist die Antwort dieselbe — 2.350.

---

## 4. Lass uns gemeinsam lösen

Rechne: 1.008 + 0 = ?
Adding 0 — nothing changes.
1,008 + 0 = 1,008
1,008

## 6. Häufiger Fehler — Achtung!

Rechne: 1.789 + 0 = ?
0 addieren — 0 addiert nichts, die Zahl bleibt.
1,789 + 0 = 1,789
1,789
