---

## 1. Was lernen wir?

Heute lernen wir, was passiert, wenn du 0 von einer Zahl subtrahierst.
0 nimmt nichts weg — die Zahl bleibt gleich.

---

## 2. Einfache Erklärung

Regel:
Jede Zahl − 0 = dieselbe Zahl.
789 − 0 = 789
3,200 − 0 = 3,200
Warum? 0 bedeutet „nichts wegzunehmen“.
Wenn du 789 Dinge hast und 0 wegnimmst — hast du immer noch 789.
Achtung:
Das ist anders als 789 − 789 (was 0 ist).
Hier subtrahierst du 0, nicht die Zahl selbst.

---

## 3. Anschauliches / konkretes Beispiel

5,640 − 0 = ?
5,640 − 0 = 5,640
Subtracting "nothing" — 5,640 stays.

---

## 4. Lass uns gemeinsam lösen

Rechne: 2.501 − 0 = ?
Subtracting 0 — nothing changes.
2,501 − 0 = 2,501
2,501

4,125 − 0 = 4,125
4,125
