## 1. Was lernen wir?

Heute finden wir Schritt für Schritt einen fehlenden Winkel in einem Dreieck — mit einer Gleichung und x für den unbekannten Winkel.
Nicht nur „180° minus Addition“ — sondern: x + Winkel 1 + Winkel 2 = 180°.

---

## 2. Einfache Erklärung

:::geometry-diagram
type: angle_basic
:::

In Dreieck ABC, wir label missing Winkel x.
Equation: x + A + B = 180°
Schritte:
1.
Setze die bekannten Winkel ein
2.
Add known ones
3.
Löse: x = 180° − (A + B)
4. prüfen: x + A + B = 180°

---

## 3. Beispiel

In triangle: 55°, 65°, und x (missing).
Equation: x + 55° + 65° = 180°
Step a: 55° + 65° = 120°
Step b: x + 120° = 180°
Step c: x = 180° − 120° = 60°
Prüfen: 60° + 55° + 65° = 180°

---

## 4. Lass uns gemeinsam lösen

In triangle ABC angle = 55°, angle B = 65°. finde angle C — label it x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Step 4 (prüfen): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Probiere es selbst

In ein Dreieck: 40° und 65° — write equation x + 40° + 65° = 180° und find x.
Versuch, es selbst zu lösen.
Auf der nächsten Seite prüfen wir gemeinsam die Schritte und die Antwort.

---

## 6. Lass uns gemeinsam prüfen

In ein Dreieck: Winkel 40° und 65° — find third Winkel x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Step 4 (prüfen): 75° + 40° + 65° = 180°
x = 75°

---

## 7. Lass uns üben!

Hier finden wir einen fehlenden Winkel mit einer Gleichung und einer Probe.
In der Übung findest du x +… = 180° — addiere die bekannten Winkel, löse nach x und prüfe!
