## 6. Common mistake — watch out!

15,000 − __ = 6,500 — ¿cuál es el número que falta?
Pregunta: 15,000 menos ¿qué? es igual a 6,500?
__ = 15,000 − 6,500 = 8,500
Comprobación: 15,000 − 8,500 = 6,500
__ = 8,500
