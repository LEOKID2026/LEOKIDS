## 1. What are we learning?

Hoy vamos a resolver un problema — cuando la pregunta pide cuántos más tiene una persona que otra.
Necesitas la diferencia — el mayor menos el menor, ¡no el total!

---

## 2. Simple explanation

Esquema para problemas de comparación:
¿Qué sabes? Dos cantidades — por ejemplo 420 litros y 275 litros
¿Qué te preguntan? ¿Cuál es la diferencia — quién tiene más?
¿Qué haces? Siempre: mayor − menor
420 − 275 = 145 — hay 145 litros más.
"Más" = diferencia — ¡no el total!

---

## 3. Visual / concrete example

Danny tiene $4,800 en ahorros y Mia tiene $4,200.
¿Cuánto más tiene Danny?
4,800 − 4,200 = $600 más

---

## 4. Let's solve together

Danny tiene $3,200 y Mia tiene $2,850. ¿Cuánto más tiene Danny?
3,200 > 2,850.
3,200 − 2,850 = 350
$350 más.

## 6. Common mistake — watch out!

Danny tiene $3,200 y Mia tiene $2,850.
¿Cuánto más tiene Danny?
"Cuántos más" = diferencia → resta mayor menos menor
3,200 − 2,850 = 350
Danny tiene $350 más
