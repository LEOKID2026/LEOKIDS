## 1. What are we learning?

Hoy vamos a aprender a sumar tres números — hasta un total de unos 100,000.
Puedes sumar primero dos, luego el tercero — paso a paso.

---

## 2. Simple explanation

Pasos:
Suma tres números — primero dos, luego el tercero
Empieza por las unidades — lleva cuando haga falta
Continúa con decenas, centenas, miles, decenas de millar
2,000 + 1,500 + 800:
2,000 + 1,500 = 3,500
3,500 + 800 = 4,300

---

## 3. Visual / concrete example

12,000 + 8,500 + 3,200:
12,000 + 8,500 = 20,500
20,500 + 3,200 = 23,700

---

## 4. Let's solve together

Calcula 15,000 + 9,500 + 5,500 = ?
9,500 + 5,500 = 15,000 (un par práctico).
15,000 + 15,000 = 30,000
30,000.

Calcula: 5,000 + 3,500 + 1,200 = ?

---

## 6. Common mistake — watch out!

Calcula: 5,000 + 3,500 + 1,200 = ?
Suma primero dos: 5,000 + 3,500 = 8,500
Suma el tercero: 8,500 + 1,200 = 9,700
5,000 + 3,500 + 1,200 = 9,700
