## 2. Simple explanation

3,250 + __ = 8,400
Pregunta: ¿qué le sumas a 3,250 para llegar a 8,400?
__ = 8,400 − 3,250 = 5,150
Comprobación: 3,250 + 5,150 = 8,400

## 6. Common mistake — watch out!

__ + 5,300 = 12,700 — ¿cuál es el número que falta?
__ = 12,700 − 5,300
__ = 7,400
Comprobación: 7,400 + 5,300 = 12,700
__ = 7,400
