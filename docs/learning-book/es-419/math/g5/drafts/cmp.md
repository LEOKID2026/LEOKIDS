## 1. What are we learning?

Hoy vamos a aprender a comparar números grandes hasta 100,000 — para saber cuál es mayor, cuál es menor, o si son iguales.
Usaremos los símbolos > (mayor que), < (menor que), = (igual a).

---

## 2. Simple explanation

¿Cómo se comparan números grandes?
Primero revisa el dígito de las decenas de millar — el número con el dígito mayor es más grande (lee de izquierda a derecha)
Si son iguales — revisa las miles
Si son iguales — revisa las centenas, decenas, unidades
52,400 y 52,390:
- decenas de millar: 5 = 5
- miles: 2 = 2
- centenas: 4 > 3 → 52,400 > 52,390

---

## 3. Visual / concrete example

Compara: 67,820 y 67,802
Decenas de millar: 6 = 6
Miles: 7 = 7
Centenas: 8 = 8
Decenas: 2 > 0 → 67,820 > 67,802

## 4. Let's solve together

Compara 41,500 y 41,580 — ¿qué símbolo es correcto?
Decenas de millar, miles, centenas — todos iguales (41,5__).
Decenas: 0 < 8.
41,500 < 41,580.
41,500 < 41,580

## 6. Common mistake — watch out!

Compara: 83,750 ? 83,705
Decenas de millar: 8 = 8
Miles: 3 = 3
Centenas: 7 = 7
Decenas: 5 > 0 → 83,750 es mayor
83,750 > 83,705
