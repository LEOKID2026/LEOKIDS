---

## 1. What are we learning?

Hoy vamos a aprender a sumar números decimales — con un punto decimal (por ejemplo 2.3 + 1.4).
Importante: alinea los puntos decimales — parte entera bajo parte entera, décimas bajo décimas.

---

## 2. Simple explanation

2.3 + 1.4
2 + 1 = 3 (entero)
0.3 + 0.4 = 0.7 (después del punto)
2.3 + 1.4 = 3.7
Regla: suma como si no hubiera punto y luego coloca el punto en el mismo lugar.

---

## 3. Visual / concrete example

4.2 + 3.5
Entero: 4 + 3 = 7
Décimas: 2 + 5 = 7
4.2 + 3.5 = 7.7

---

## 4. Let's solve together

Calcula: 1.6 + 2.2 = ?
Entero: 1 + 2 = 3
Décimas: 6 + 2 = 8 → 0.8
1.6 + 2.2 = 3.8

## 6. Common mistake — watch out!

Calcula: 3.6 + 2.1
Entero: 3 + 2 = 5
Décimas: 6 + 1 = 7 → 0.7
3.6 + 2.1 = 5.7
