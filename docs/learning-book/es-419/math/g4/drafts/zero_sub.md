## 1. What are we learning?

Hoy vamos a aprender qué pasa cuando restas 0 de un número.
0 no "quita" nada — el número se queda igual.

---

## 2. Simple explanation

Regla:
Cualquier número − 0 = el mismo número.
789 − 0 = 789
3,200 − 0 = 3,200
¿Por qué? 0 significa "nada que quitar".
Si tienes 789 cosas y quitas 0 — sigues teniendo 789.
Ojo:
Esto es distinto de 789 − 789 (que es 0).
Aquí restas 0, no el número mismo.
