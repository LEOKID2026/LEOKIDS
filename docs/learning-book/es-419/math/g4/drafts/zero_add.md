## 1. What are we learning?

Hoy vamos a aprender qué pasa cuando sumas 0 a un número.
0 es un número especial — no cambia la respuesta en la suma.

---

## 2. Simple explanation

Regla:
Cualquier número + 0 = el mismo número.
0 no suma nada — el número se queda igual.
456 + 0 = 456
0 + 789 = 789
¿Por qué? 0 significa "nada que sumar".
Si tienes 456 cosas y sumas 0 — sigues teniendo 456.
Incluso con números grandes — la regla es la misma.

---

## 3. Visual / concrete example

2,350 + 0 = ?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
En ambos casos la respuesta es la misma — 2,350.
