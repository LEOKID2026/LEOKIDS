## 1. What are we learning?

Hoy vamos a aprender a clasificar números rápidamente como pares o impares — incluso hasta 10,000.
No necesitas analizar todo el número: solo mira el dígito de las unidades.

---

## 2. Simple explanation

La regla del último dígito:
246 — dígito de las unidades 6 → par (¡de inmediato!)
8,731 — dígito de las unidades 1 → impar (¡de inmediato!)
¿Por qué funciona? Cada diez, cada cien y cada mil son pares — solo las unidades pueden "dejar uno de sobra".

---

## 3. Visual / concrete example

3,512 — ¿par o impar?
Clasificación rápida: dígito de las unidades 2 → 2 es par → 3,512 es par.
Comprueba: 3,512 = 1,756 + 1,756
No necesitas analizar todo 3,512 — solo el último dígito.

## 6. Common mistake — watch out!

¿3,578 es par o impar?
Mira solo el dígito de las unidades: 8.
8 está en la lista 0, 2, 4, 6, 8 → par.
3,578 es par
