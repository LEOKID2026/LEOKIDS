## 1. What are we learning?

Hoy vamos a aprender secuencias con saltos grandes — no solo +1 o +5, sino saltos como +50 o +100.
Encuentra la regla y continúa — hasta 10,000.

---

## 2. Simple explanation

Una secuencia = números en fila que siguen una regla.
Salto fijo: en cada paso sumas (o restas) el mismo número.
100, 150, 200, 250, …
- 150 − 100 = 50
- 200 − 150 = 50
- El salto: +50 cada vez
El siguiente número: 250 + 50 = 300

---

## 3. Visual / concrete example

3,250, 3,300, 3,350, 3,400, ?
3,300 − 3,250 = 50
3,350 − 3,300 = 50
3,400 − 3,350 = 50
Salto: +50
3,400 + 50 = 3,450
Respuesta: 3,450

## 4. Let's solve together

Continúa: 2,800, 2,850, 2,900, 2,950, ?
2,850 − 2,800 = 50 El salto es +50.
2,950 + 50 = 3,000
3,000

## 6. Common mistake — watch out!

Continúa la secuencia: 1,000, 1,100, 1,200, ?
1,100 − 1,000 = 100 El salto es +100.
Comprueba: 1,200 − 1,100 = 100 — el mismo salto.
1,200 + 100 = 1,300
1,300
