## 1. What are we learning?

Hoy vamos a aprender qué pasa cuando multiplicas un número por 0.
0 en la multiplicación es especial — la respuesta siempre es 0.

---

## 2. Simple explanation

Regla:
Cualquier número × 0 = 0.
52 × 0 = 0
0 × 347 = 0
¿Por qué?
Multiplicar por 0 significa "cero grupos" o "cero veces".
No hay nada — la respuesta es 0.
Incluso un número grande × 0 = 0:
9,999 × 0 = 0

---

## 3. Visual / concrete example

125 × 0 = ?
125 × 0 = 0
0 grupos de 125 = nada = 0.
0 × 125 = 0 — aunque el 0 vaya primero, la respuesta es 0.
