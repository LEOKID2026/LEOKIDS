## 1. What are we learning?

En esta sección vamos a aprender a sumar tres números — uno tras otro o en grupos cómodos.
Por ejemplo: 350 + 120 + 80.

---

## 2. Simple explanation

Formas de sumar tres números:
Uno tras otro: (350 + 120) + 80
Primero el par cómodo: 350 + (120 + 80) — cuando 120 + 80 = 200
Redondeo: 398 + 102 + 50 → (398 + 102) + 50 = 500 + 50
Importante: suma los tres números — ¡no te detengas después de dos!
350 + 120 + 80:
350 + 120 = 470
470 + 80 = 550

---

## 3. Visual / concrete example

2,450 + 350 + 1,200
2,450 + 1,200 = 3,650 (primero los dos números más grandes)
3,650 + 350 = 4,000
2,450 + 350 + 1,200 = 4,000

## 4. Let's solve together

Resuelve: 820 + 180 + 500 = ?
820 + 180 = 1,000 (par cómodo — termina en 0).
1,000 + 500 = 1,500
820 + 180 + 500 = 1,500

## 6. Common mistake — watch out!

Resuelve: 450 + 120 + 80 = ?
Busca un par cómodo: 120 + 80 = 200
450 + 200 = 650
450 + 120 + 80 = 650
