## 1. What are we learning?

Hoy vamos a resolver ecuaciones de resta con un número que falta — por ejemplo __ − 45 = 120.
Necesitamos encontrar el número más grande — el de donde restamos.

---

## 2. Simple explanation

__ − 45 = 120
Pregunta: de algún número restamos 45 y obtuvimos 120 — ¿cuál es el número?
120 + 45 = 165
165 − 45 = 120
Regla: número que falta antes del menos = resultado + el número que se resta.

---

## 3. Visual / concrete example

__ − 72 = 208
208 + 72 = 280
280 − 72 = 208

---

## 4. Let's solve together

__ − 38 = 142 — ¿cuál es el número que falta?
142 + 38 = 180
180 − 38 = 142
El número que falta es 180.

## 6. Common mistake — watch out!

__ − 63 = 175 — ¿cuál es el número que falta?
Número que falta antes del menos — suma el resultado y el número que se resta.
175 + 63 = 238
Comprueba: 238 − 63 = 175
El número que falta es 238
