## 1. What are we learning?

Hoy vamos a resolver ecuaciones de suma con números grandes — hasta 1,000.
Necesitamos encontrar qué falta en __ para que la ecuación sea verdadera.

---

## 2. Simple explanation

125 + __ = 380
Pregunta: ¿qué sumas a 125 para llegar a 380?
380 − 125 = 255
125 + 255 = 380
Regla: número que falta = total (después del =) menos el número que ya tienes.

---

## 3. Visual / concrete example

240 + __ = 500
500 − 240 = 260
240 + 260 = 500

---

## 4. Let's solve together

318 + __ = 600 — ¿cuál es el número que falta?
600 − 318 = 282
Comprueba: 318 + 282 = 600
El número que falta es 282.

## 6. Common mistake — watch out!

180 + __ = 460 — ¿cuál es el número que falta?
Número que falta = total menos el número que ya tienes.
460 − 180 = 280
Comprueba: 180 + 280 = 460
El número que falta es 280
