## 1. What are we learning?

Hoy vamos a aprender a sumar dos números hasta 200,000.
Trabaja de unidades → decenas → centenas → miles → decenas de millar → centenas de millar, con llevadas.

---

## 2. Simple explanation

12,450 + 3,875:
- unidades: 0+5=5
- decenas: 5+7=12 → 2, llevas 1
- centenas: 4+8+1=13 → 3, llevas 1
- miles: 2+3+1=6
- decenas de millar: 1+0=1
= 16,325

---

## 3. Visual / concrete example

48,750 + 25,680 = 74,430
Comprueba: 74,430 − 25,680 = 48,750

---

## 4. Let's solve together

Calcula 48,750 + 25,680 = ?
Unidades: 0 + 0 = 0
Decenas: 5 + 8 = 13 → escribe 3, llevas 1
Centenas: 7 + 6 + 1 = 14 → escribe 4, llevas 1
Miles: 8 + 5 + 1 = 14 → escribe 4, llevas 1
Decenas de millar: 4 + 2 + 1 = 7
48,750 + 25,680 = 74,430

## 6. Common mistake — watch out!

Calcula: 34,267 + 15,486
Unidades: 7+6=13 → 3, llevas 1.
Decenas: 6+8+1=15 → 5, llevas 1.
Centenas: 2+4+1=7
Miles: 4+5=9
Decenas de millar: 3+1=4
La respuesta: 49,753
