## 6. Common mistake — watch out!

Calcula: 8.40 − 3.75
Centésimas: 0<5 → presta de las décimas. 10−5=5.
Décimas: 3 (después de prestar) < 7 → presta de las unidades. 13−7=6.
Unidades: 7 (después de prestar) − 3 = 4.
Comprueba: 4.65 + 3.75 = 8.40
La respuesta: 4.65
