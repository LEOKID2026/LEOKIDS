## 1. What are we learning?

Hoy vamos a aprender los decimales periódicos — dígitos que se repiten para siempre.
1/3 = 0.333…

---

## 2. Simple explanation

Cuando la división no termina — a veces obtienes un patrón que se repite.
1 ÷ 3 = 0.333333… — el dígito 3 se repite.
Se escribe: 0.3̄ (una barra sobre el 3) o 0.333…

---

## 3. Visual / concrete example

2/3 = 0.666… — el dígito que se repite es 6.
1/6 = 0.1666… — el dígito que se repite es 6.

---

## 4. Let's solve together

¿Qué es 1/3 como decimal?
1 ÷ 3 = 0.333…
0.333… (3 periódico).

## 6. Common mistake — watch out!

Escribe 2/3 como número decimal
2 ÷ 3 = ?
3 cabe en 20 → 6 veces (18), resto 2; otra vez 3 cabe en 20 → 6… → se repite.
2 ÷ 3 = 0.666… — el dígito que se repite es 6.
La respuesta: 0.666… (6 periódico)
