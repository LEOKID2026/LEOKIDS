## 1. What are we learning?

Hoy vamos a aprender a sumar tres números — hasta 200,000.
Puedes trabajar de derecha a izquierda, o sumar primero dos números.

---

## 2. Simple explanation

85,000 + 12,500 + 2,500 — tres números grandes:
Forma 1: (85,000 + 12,500) + 2,500 = 97,500 + 2,500 = 100,000
Forma 2: 12,500 + 2,500 = 15,000; 85,000 + 15,000 = 100,000
Importante: suma los tres números — ¡no te detengas después de dos!

---

## 3. Visual / concrete example

62,000 + 18,500 + 9,500:
62,000 + 18,500 = 80,500
80,500 + 9,500 = 90,000

## 4. Let's solve together

45,000 + 27,500 + 7,500 = ?
27,500 + 7,500 = 35,000 (un par conveniente).
45,000 + 35,000 = 80,000
80,000.

## 6. Common mistake — watch out!

Calcula: 1,200 + 350 + 450
Elige un par conveniente: 350 + 450 = 800
1,200 + 800 = 2,000
Comprueba: se sumaron los tres números — 1,200, 350 y 450.
La respuesta: 2,000
