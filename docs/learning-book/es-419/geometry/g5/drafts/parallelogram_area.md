## 1. What are we learning?

Hoy aprenderemos el área de un paralelogramo.
Área = base × altura.
La altura — la distancia perpendicular a la base (¡no el lado inclinado!).

---

## 2. Simple explanation

:::geometry-diagram
type: parallelogram_area
:::

En un paralelogramo:
- base — el lado que elegimos (por ejemplo 8 cm)
- altura — el segmento perpendicular desde la base hasta el lado paralelo (5 cm)
Área = base × altura
No uses el lado inclinado — solo la altura.

---

## 3. Example

Base 8 cm, altura 5 cm:
8 × 5 = 40 cm²
