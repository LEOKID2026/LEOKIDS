## 1. What are we learning?

Hoy hallaremos un ángulo faltante en un triángulo paso a paso — con una ecuación y x para el ángulo desconocido.
No solo "180° menos la suma" — sino: x + ángulo 1 + ángulo 2 = 180°.

---

## 2. Simple explanation

:::geometry-diagram
type: angle_basic
:::

En el triángulo ABC, etiquetamos el ángulo faltante como x.
Ecuación: x + A + B = 180°
Pasos:
1.
Sustituye los ángulos conocidos
2.
Suma los conocidos
3.
Resuelve: x = 180° − (A + B)
4. Comprueba: x + A + B = 180°

---

## 3. Example

En un triángulo: 55°, 65° y x (faltante).
Ecuación: x + 55° + 65° = 180°
Paso a: 55° + 65° = 120°
Paso b: x + 120° = 180°
Paso c: x = 180° − 120° = 60°
Comprobación: 60° + 55° + 65° = 180°

---

## 4. Let's solve together

En el triángulo ABC el ángulo A = 55°, el ángulo B = 65°. Halla el ángulo C — etiquétalo como x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Paso 4 (comprobación): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Try it yourself

En un triángulo: 40° y 65° — escribe la ecuación x + 40° + 65° = 180° y halla x.
Intenta resolverlo por tu cuenta.
En la página siguiente revisaremos juntos los pasos y la respuesta.

## 6. Let's check together

En un triángulo: ángulos 40° y 65° — halla el tercer ángulo x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Paso 4 (comprobación): 75° + 40° + 65° = 180°
x = 75°
