## 6. Mari kita periksa bersama

Latihan: "Kita mungkin pergi ke beach pada Saturday."

mungkin berarti maybe — possibility, tidak sesuatu certain.

mungkin + verb (tanpa "ke"): mungkin pergi.

Jadi penuh kalimat adalah: Kita mungkin pergi ke beach pada Saturday.
