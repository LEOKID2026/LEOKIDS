## 2. Penjelasan sederhana

Jika + Present, akan — future result:

Jika kita protect oceans, future generations akan benefit.

Jika orang kerja bersama, dunia akan improve.

## 6. Mari kita periksa bersama

Latihan: "Jika kita protect forests, animals akan survive."

Type 1: Jika + Present Simple, akan + verb.

"Protect" adalah Present; "akan survive" adalah future result.

Jadi penuh kalimat adalah: Jika kita protect forests, animals akan survive.
