## 6. Mari kita periksa bersama

Latihan: "International organizations bantu selesaikan global soal."

"Organizations" adalah plural — kita gunakan bantu tanpa s.

bantu + verb (tanpa "ke"): bantu selesaikan.

Jadi penuh kalimat adalah: International organizations bantu selesaikan global soal.
