## 1. Apa yang kita pelajari?

Hari ini kamu akan belajar Conditionals — Type 0 (aturan itu selalu benar) dan Type 1 (mungkin future).
Jika itu rains, kita akan tetap di rumah.

---

## 2. Penjelasan sederhana

Type 0 — selalu benar: Jika kamu panas ice, itu melts.

Type 1 — Jika + Present, akan + verb:
Jika itu rains, kita akan tetap di rumah.

## 6. Mari kita periksa bersama

Latihan: "Jika kamu lakukan kamu homework, kamu akan dapatkan good kelas."

Type 1: Jika + Present Simple, akan + verb.

"Lakukan kamu homework" adalah Present; "akan dapatkan" adalah future result.

Jadi penuh kalimat adalah: Jika kamu lakukan kamu homework, kamu akan dapatkan good kelas.
