## 6. Mari kita periksa bersama

Latihan: "Itu adalah snowing hari ini."

Weather happening siku-siku sekarang uses Present Continuous: adalah + verb + ing.

"Snow" menjadi "snowing"; "hari ini" tells us ketika.

Jadi penuh kalimat adalah: Itu adalah snowing hari ini.
