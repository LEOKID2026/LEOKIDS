## 6. Mari kita periksa bersama

Latihan: "Kita gunakan internet untuk lessons."

"Kita" — sesudah kita kita lakukan tidak jumlahkan s ke verb gunakan.

" internet" adalah apa kita gunakan; "untuk lessons" tells us mengapa.

Jadi penuh kalimat adalah: Kita gunakan internet untuk lessons.
