## 1. Apa yang kita pelajari?

Hari ini kita akan belajar perkiraan penjumlahan jawaban — tidak hitung tepat, but dapatkan close.
≈ berarti kira-kira, mendekati.

---

## 2. Penjelasan sederhana

3,487 + 2,512 ≈ ?
Bulatkan ke nearest seribu:
3,487 ≈ 3,500
2,512 ≈ 2,500
3,500 + 2,500 = 6,000
3,487 + 2,512 ≈ 6,000

---

## 3. Contoh visual / konkret

1,298 + 4,703 ≈ ?
1,298 ≈ 1,300; 4,703 ≈ 4,700
1,300 + 4,700 = 6,000

---

## 4. Mari kita selesaikan bersama

3,487 + 2,512 ≈ ?
3,487 ≈ 3,500; 2,512 ≈ 2,500
3,500 + 2,500 = 6,000
≈ 6,000

---

## 5. Coba sendiri

6,250 + 2,730 ≈ ?
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

6,250 + 2,730 ≈ ?
Bulatkan ke nearest seribu: 6,250 ≈ 6,000; 2,730 ≈ 3,000
6,000 + 3,000 = 9,000
6,250 + 2,730 ≈ 9,000
