## 1. Apa yang kita pelajari?

Hari ini kita akan belajar bulatkan keseluruhan bilangan ke nearest sepuluh, seratus, seribu, dan sepuluh-seribu.
Pembulatan membantu kamu perkiraan jawaban di matematika dan lakukan quick mental matematika.

---

## 2. Penjelasan sederhana

Langkah pembulatan:
Lihat digit di kanan tempat yang kamu bulatkan
Jika 0, 1, 2, 3, atau 4 — bulatkan ke bawah (tetap sama)
Jika 5, 6, 7, 8, atau 9 — bulatkan ke atas (tambah 1)
Pembulatan ke nearest sepuluh:
Lihat satuan
Pembulatan ke nearest seratus:
Lihat puluhan
Pembulatan ke nearest seribu:
Lihat ratusan
Pembulatan ke nearest sepuluh-seribu:
Lihat ribuan
38,750 ke nearest sepuluh-seribu:
Ribuan digit 8 → bulatkan up → 40,000

---

## 3. Contoh visual / konkret

38,750 ke nearest sepuluh:
- Satuan digit 0 → 38,750
38,750 ke nearest seribu:
- Ratusan digit 7 → bulatkan up → 39,000
38,750 ke nearest sepuluh-seribu:
- Ribuan digit 8 → bulatkan up → 40,000

---

## 4. Mari kita selesaikan bersama

Bulatkan 38,750 ke seribu terdekat.
Ratusan digit: 7 → bulatkan up.
38,750 → 39,000
39,000

---

## 5. Coba sendiri

Bulatkan 46,380 ke seribu terdekat.
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

Bulatkan 46,380 ke seribu terdekat.
Lihat ratusan digit: 3
3 < 5 → bulatkan turun (tetap di lower seribu)
46,380 → 46,000
46,380 ≈ 46,000
