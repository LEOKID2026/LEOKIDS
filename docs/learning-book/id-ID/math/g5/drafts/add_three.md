## 1. Apa yang kita pelajari?

Hari ini kita akan belajar menjumlahkan tiga bilangan — sampai total dari tentang 100,000.
Kamu bisa jumlahkan dua pertama, lalu ketiga — langkah oleh langkah.

---

## 2. Penjelasan sederhana

Langkah-langkah:
Jumlahkan tiga bilangan — pertama dua, lalu ketiga
Kerja dari satuan — simpan ketika kamu perlu ke
Continue dengan puluhan, ratusan, ribuan, sepuluh-ribuan
2,000 + 1,500 + 800:
2,000 + 1,500 = 3,500
3,500 + 800 = 4,300

---

## 3. Contoh visual / konkret

12,000 + 8,500 + 3,200:
12,000 + 8,500 = 20,500
20,500 + 3,200 = 23,700

## 4. Mari kita selesaikan bersama

Kerja 15,000 + 9,500 + 5,500 =?
9,500 + 5,500 = 15,000 (handy pasangan).
15,000 + 15,000 = 30,000
30,000.

---

## 5. Coba sendiri

Hitung: 5,000 + 3,500 + 1,200 =?
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

Hitung: 5,000 + 3,500 + 1,200 =?
Jumlahkan dua pertama: 5,000 + 3,500 = 8,500
Jumlahkan ketiga: 8,500 + 1,200 = 9,700
5,000 + 3,500 + 1,200 = 9,700
