## 1. Apa yang kita pelajari?

Hari ini kamu akan belajar menjumlahkan tiga bilangan — sampai 200,000.
Kamu bisa kerja dari siku-siku ke kiri, atau jumlahkan dua bilangan pertama.

---

## 2. Penjelasan sederhana

85,000 + 12,500 + 2,500 — tiga large bilangan:
Way 1: (85,000 + 12,500) + 2,500 = 97,500 + 2,500 = 100,000
Way 2: 12,500 + 2,500 = 15,000; 85,000 + 15,000 = 100,000
Penting: jumlahkan semua tiga bilangan — lakukan tidak stop sesudah dua!

---

## 3. Contoh visual / konkret

62,000 + 18,500 + 9,500:
62,000 + 18,500 = 80,500
80,500 + 9,500 = 90,000

---

## 4. Mari kita selesaikan bersama

45,000 + 27,500 + 7,500 = ?
27,500 + 7,500 = 35,000 (convenient pasangan).
45,000 + 35,000 = 80,000
80,000.

---

## 5. Coba sendiri

Hitung: 1,200 + 350 + 450 =?
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

Hitung: 1,200 + 350 + 450
Pilih convenient pasangan: 350 + 450 = 800
1,200 + 800 = 2,000
Periksa: semua tiga bilangan adalah dijumlahkan — 1,200, 350, dan 450.
jawaban: 2,000
