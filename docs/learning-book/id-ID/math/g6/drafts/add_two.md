## 1. Apa yang kita pelajari?

Hari ini kamu akan belajar menjumlahkan dua bilangan sampai 200,000.
Kerja dari satuan → puluhan → ratusan → ribuan → sepuluh ribuan → seratus ribuan, dengan menyimpan.

---

## 2. Penjelasan sederhana

12,450 + 3,875:
- satuan: 0+5=5
- puluhan: 5+7=12 → 2, simpan 1
- ratusan: 4+8+1=13 → 3, simpan 1
- ribuan: 2+3+1=6
- sepuluh ribuan: 1+0=1
= 16,325

---

## 3. Contoh visual / konkret

48,750 + 25,680 = 74,430
Periksa: 74,430 − 25,680 = 48,750

---

## 4. Mari kita selesaikan bersama

Hitung 48,750 + 25,680 =?
Satuan: 0 + 0 = 0
Puluhan: 5 + 8 = 13 → tulis 3, simpan 1
Ratusan: 7 + 6 + 1 = 14 → tulis 4, simpan 1
Ribuan: 8 + 5 + 1 = 14 → tulis 4, simpan 1
Sepuluh ribuan: 4 + 2 + 1 = 7
48,750 + 25,680 = 74,430

---
