**Cakupan konten:** Penjumlahan dengan **desimal titik** — satu digit sesudah titik. Tidak dua desimal digit.

---

## 1. Apa yang kita pelajari?

Hari ini kamu akan belajar menjumlahkan desimal bilangan — dengan desimal titik (misalnya 2.3 + 1.4).
Penting: garis up desimal poin — keseluruhan bagian di bawah keseluruhan bagian, tenths di bawah tenths.

---

## 2. Penjelasan sederhana

2.3 + 1.4
2 + 1 = 3 (keseluruhan)
0.3 + 0.4 = 0.7 (sesudah titik)
2.3 + 1.4 = 3.7
Aturan: jumlahkan as jika ada tidak titik, lalu letakkan titik di sama tempat.

---

## 3. Contoh visual / konkret

4.2 + 3.5
Keseluruhan: 4 + 3 = 7
Tenths: 2 + 5 = 7
4.2 + 3.5 = 7.7

---

## 4. Mari kita selesaikan bersama

Hitung: 1.6 + 2.2 =?
Keseluruhan: 1 + 2 = 3
Tenths: 6 + 2 = 8 → 0.8
1.6 + 2.2 = 3.8

---

## 5. Coba sendiri

Hitung: 3.6 + 2.1 =?
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

Hitung: 3.6 + 2.1
Keseluruhan: 3 + 2 = 5
Tenths: 6 + 1 = 7 → 0.7
3.6 + 2.1 = 5.7

---

Sekarang kamu sudah tahu cara menjumlahkan bilangan desimal.
