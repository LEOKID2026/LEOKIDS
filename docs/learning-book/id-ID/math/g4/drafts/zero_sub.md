## 1. Apa yang kita pelajari?

Hari ini kita akan belajar apa happens ketika kamu kurangkan 0 dari bilangan.
0 tidak "ambil" apa saja — bilangan tetap sama.

---

## 2. Penjelasan sederhana

Aturan:
Satu bilangan − 0 = sama bilangan.
789 − 0 = 789
3,200 − 0 = 3,200
Mengapa? 0 berarti "tidak ada ke ambil away."
Jika kamu memiliki 789 things dan ambil away 0 — kamu masih memiliki 789.
Watch :
Ini adalah berbeda dari 789 − 789 (yang mana adalah 0).
Di sini kamu kurangkan 0, tidak bilangan sendiri.

---

## 3. Contoh visual / konkret

5,640 − 0 = 5,640
Pengurangan "tidak ada" — 5,640 tetap.
