---

## 1. Apa yang kita pelajari?

Hari ini kita akan belajar apa happens ketika kamu jumlahkan 0 ke bilangan.
0 adalah special bilangan — itu tidak perubahan jawaban di penjumlahan.

---

## 2. Penjelasan sederhana

Aturan:
Satu bilangan + 0 = sama bilangan.
0 tidak jumlahkan apa saja — bilangan tetap sama.
456 + 0 = 456
0 + 789 = 789
Mengapa? 0 berarti "tidak ada ke jumlahkan."
Jika kamu memiliki 456 things dan jumlahkan 0 — kamu masih memiliki 456.
Bahkan dengan besar bilangan — aturan adalah sama.

---

## 3. Contoh visual / konkret

2,350 + 0 = ?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
Di keduanya cases jawaban adalah sama — 2,350.

---

## 4. Mari kita selesaikan bersama

Hitung: 1,008 + 0 =?
Penjumlahan 0 — tidak ada changes.
1,008 + 0 = 1,008
1,008

---

## 5. Coba sendiri

Hitung: 1,789 + 0 =?
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Kesalahan umum — hati-hati!

Hitung: 1,789 + 0 =?
Penjumlahan 0 — 0 tidak jumlahkan apa saja, bilangan tetap.
1,789 + 0 = 1,789
1,789
