---

## 1. Apa yang kita pelajari?

Hari ini kita akan temukan tetangga di besar bilangan — sampai 10,000.
±1 bahkan ketika crossing seribu — misalnya 1,999 → 2,000 → 2,001.

---

## 2. Penjelasan sederhana

Tetangga sebelum = −1
Tetangga sesudah = +1
2,450:
- sebelum: 2,449
- sesudah: 2,451
Crossing seribu:
- 1,999 → sesudah = 2,000
- 2,000 → sebelum = 1,999
Tempat nilai: ketika kamu cross seribu, semua digit bisa perubahan — but jump adalah masih 1.

---

## 3. Contoh visual / konkret

3,628:
3,628 − 1 = 3,627
3,628 + 1 = 3,629
2,999 → 3,000: tetangga sesudah 2,999 = 3,000 — crossing seribu, masih hanya +1.
3,626 — 3,627 — [3,628] — 3,629 — 3,630

---

## 4. Mari kita selesaikan bersama

Apa tetangga dari 2,450?
Sebelum = 2,450 − 1 = 2,449
Sesudah = 2,450 + 1 = 2,451
2,449 dan 2,451

## 6. Kesalahan umum — hati-hati!

Apa tetangga sebelum dan sesudah bilangan 3,999?
Sebelum = 3,999 − 1 = 3,998.
Sesudah = 3,999 + 1 = 4,000 (crossing seribu — masih hanya +1).
Sebelum 3,998, sesudah 4,000
