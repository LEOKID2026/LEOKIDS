## 1. Apa yang kita pelajari?

Hari ini kita akan temukan yang hilang sudut di segitiga langkah oleh langkah — dengan equation dan x untuk tidak diketahui sudut.
Tidak hanya "180° minus penjumlahan" — but: x + sudut 1 + sudut 2 = 180°.

---

## 2. Penjelasan sederhana

:::geometry-diagram
type: angle_basic
:::

Di segitiga ABC, kita label yang hilang sudut x.
Equation: x + + B = 180°
Langkah-langkah:
1.
Plug di diketahui sudut
2.
Jumlahkan diketahui satuan
3.
Selesaikan: x = 180° − (+ B)
4. Periksa: x + + B = 180°

---

## 3. Contoh

Di segitiga: 55°, 65°, dan x (yang hilang).
Equation: x + 55° + 65° = 180°
Langkah: 55° + 65° = 120°
Langkah b: x + 120° = 180°
Langkah c: x = 180° − 120° = 60°
Periksa: 60° + 55° + 65° = 180°

---

## 4. Mari kita selesaikan bersama

Di segitiga ABC sudut = 55°, sudut B = 65°. Temukan sudut C — label itu x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Langkah 4 (periksa): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Coba sendiri

Di segitiga: 40° dan 65° — tulis equation x + 40° + 65° = 180° dan temukan x.
Coba selesaikan sendiri.
Di halaman berikutnya kita akan memeriksa langkah-langkah dan jawabannya bersama.

---

## 6. Mari kita periksa bersama

Di segitiga: sudut 40° dan 65° — temukan ketiga sudut x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Langkah 4 (periksa): 75° + 40° + 65° = 180°
x = 75°

---

## 7. Mari berlatih!

Di sini kita temukan yang hilang sudut dengan equation dan periksa.
Dalam latihan kamu akan temukan x +… = 180° — jumlahkan diketahui sudut, selesaikan untuk x, dan periksa!
