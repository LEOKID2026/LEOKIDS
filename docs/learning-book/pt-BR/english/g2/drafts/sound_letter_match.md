## 1. O que estamos aprendendo?

Hoje fortaleceremos a conexão entre som e letra.
Quando ouvimos o som de “m” no início de uma palavra, procuramos a letra correspondente.
Quando olhamos para uma letra, pensamos no som que ela pode emitir em uma palavra.

---

## 2. Explicação simples

Ouvimos um som “m” no início de uma palavra – procuramos a letra M.
Ouvimos o som de “s” no início de uma palavra – procuramos a letra S.
Na palavra gato, ouvimos um som “k” no início – procuramos a letra C.
Vemos B – pensamos em um som “b” no início de uma palavra.
Vemos T – pensamos no som de “t” no início de uma palavra.

---

## 3. Exemplo

Ouvimos um som de “m” no início de uma palavra – procuramos por M.
Vemos F – pensamos no som “f” no início de uma palavra.

---

## 4. Vamos resolver juntos

Qual letra corresponde ao primeiro som da palavra gato?
Cat começa com um som “k”.
Na palavra gato, esse som é escrito com a letra C.
C
