## 1. O que estamos aprendendo?

Hoje revisamos sons em inglês.
Ouviremos os sons no início das palavras e distinguiremos palavras que soam semelhantes.
Por exemplo: morcego e caneta, cachorro e top.

---

## 2. Explicação simples

Na palavra morcego, ouvimos um som “b” no início.
Na palavra caneta, ouvimos um som “p” no início.
Na palavra cachorro, ouvimos um som “d” no início.
Na palavra top, ouvimos um som “t” no início.
O som no meio de uma palavra também é importante, como gato, cama e sentar.

---

## 3. Exemplo

Se ouvirmos um som “b” no início de uma palavra, isso não é o mesmo que um som “p”.
Se ouvirmos um som “t” no início de uma palavra, isso não é o mesmo que um som “d”.
Ouvimos devagar e reconhecemos o primeiro som.

---

## 4. Vamos resolver juntos

Que som ouvimos no início da palavra caneta?
Diga caneta lentamente.
Ouvimos um som “p” no início.
p
