## 6. Vamos verificar juntos

Exercício: “Eles já visitaram cinco países este ano”.

Present Perfect: have + particípio passado (visitado).

“Já” significa antes de agora; "este ano" significa até agora.

Então a frase completa é: Eles já visitaram cinco países este ano.
