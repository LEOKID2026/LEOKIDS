## 6. Vamos verificar juntos

Exercício: "Organizações internacionais ajudam a resolver problemas globais."

“Organizações” é plural – usamos ajuda sem s.

help + um verbo (sem “to”): ajudar a resolver.

Portanto, a frase completa é: As organizações internacionais ajudam a resolver problemas globais.
