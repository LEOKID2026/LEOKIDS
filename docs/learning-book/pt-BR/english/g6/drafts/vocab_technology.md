## 6. Vamos verificar juntos

Exercício: "Se faltar eletricidade, poderíamos usar velas."

If + Present Simple, could + verbo mostra uma possibilidade.

"Goes off" está no presente; "poderia usar" é o resultado possível.

Portanto, a frase completa é: Se faltar eletricidade, poderíamos usar velas.
