## 2. Explicação simples

Superlativo — o + mais + um adjetivo longo:

Este é o livro mais interessante que li.

Ela é a melhor jogadora do time.

## 6. Vamos verificar juntos

Exercício: "Este é o filme mais engraçado que já assisti."

"Engraçado" é um adjetivo curto - o superlativo é o + mais engraçado (dobre o y, adicione iest).

"Eu assisti" usa Present Perfect.

Então a frase completa é: Este é o filme mais engraçado que já assisti.
