## 6. Vamos verificar juntos

Exercício: "Eles podem ficar orgulhosos depois de uma vitória."

pode + sentir significa que talvez eles se sintam assim - é uma possibilidade, não algo certo.

“Orgulhoso” descreve o sentimento; "depois de uma vitória" nos diz quando.

Portanto, a frase completa é: Eles podem sentir-se orgulhosos depois de uma vitória.
