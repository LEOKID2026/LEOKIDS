## 1. O que estamos aprendendo?

Hoje aprenderemos letras minúsculas em inglês – a, b, c, até z.
Cada letra maiúscula também possui uma letra minúscula. Por exemplo: A maiúsculo corresponde a a minúsculo e B maiúsculo corresponde a b minúsculo.

---

## 2. Explicação simples

Letras minúsculas são a forma pequena das letras maiúsculas.
Por exemplo: A maiúsculo corresponde a a minúsculo e B maiúsculo corresponde a b minúsculo.
Letras minúsculas aparecem nas palavras que lemos.
Uma letra minúscula é a forma que vemos muito dentro das palavras.

---

## 3. Exemplo

Vamos conhecer duas letras minúsculas: d e t.
d é a forma minúscula de D.
t é a forma minúscula de T.
Hoje reconhecemos a forma e não confundimos as letras.

---

## 4. Vamos resolver juntos

Que letra minúscula é essa?

É assim que a letra p se parece.
