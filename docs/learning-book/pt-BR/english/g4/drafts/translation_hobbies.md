## 6. Vamos verificar juntos

Exercício: "Ele está cantando uma música (agora)."

Uma ação acontecendo agora usa Present Continuous: is + verbo + ing.

“Ele” é singular – está cantando.

Então a frase completa é: Ele está cantando uma música.
