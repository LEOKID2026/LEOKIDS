## 2. Explicação simples

Present Continuous — ação acontecendo agora:

Os pássaros estão voando.

O cachorro está correndo.

Ambas as frases descrevem algo acontecendo agora.

## 6. Vamos verificar juntos

Exercício: "Os peixes estão nadando no mar (agora)."

Uma ação acontecendo agora usa Present Continuous: are + natação.

"O peixe" é plural, então usamos nadar.

Portanto a frase completa é: Os peixes estão nadando no mar.
