## 6. Vamos verificar juntos

Exercício: "Preciso fazer exercícios todos os dias."

"Need to" + um verbo significa que devemos fazer algo.

“Exercício” aqui significa atividade física; "todos os dias" nos diz com que frequência.

Então a frase completa é: preciso fazer exercícios todos os dias.
