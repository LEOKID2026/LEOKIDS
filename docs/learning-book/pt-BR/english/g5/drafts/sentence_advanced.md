## 6. Vamos verificar juntos

Exercício: “No ano passado nossa turma fez um projeto sobre meio ambiente”.

"Ano passado" nos diz que este é o passado, então usamos um verbo no pretérito.

make torna-se feito (um verbo irregular no passado).

Então a frase completa é: Ano passado nossa turma fez um projeto sobre meio ambiente.
