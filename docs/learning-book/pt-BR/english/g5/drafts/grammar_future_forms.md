## 6. Vamos verificar juntos

Exercício: "Eles vão voar para o exterior (um plano)."

going to mostra um plano para o futuro próximo - usamos are going to + verbo.

"Eles" é plural - usamos vão voar.

Portanto, a frase completa é: Eles vão voar para o exterior.
