## 1. O que estamos aprendendo?

Hoje aprenderemos sequências com grandes saltos — não apenas +1 ou +5, mas saltos como +50 ou +100.
Encontre a regra e continue – até 10.000.

---

## 2. Explicação simples

Uma sequência = números seguidos seguindo uma regra.
Salto fixo: a cada passo você adiciona (ou subtrai) o mesmo número.
100, 150, 200, 250,…
- 150 − 100 = 50
- 200 − 150 = 50
- O salto: +50 de cada vez
O próximo número: 250 + 50 = 300

---

## 3. Exemplo visual/concreto

3.250, 3.300, 3.350, 3.400, ?
3.300 - 3.250 = 50
3.350 - 3.300 = 50
3.400 - 3.350 = 50
Salto: +50
3.400 + 50 = 3.450
Resposta: 3.450

---

## 4. Vamos resolver juntos

Continuar: 2.800, 2.850, 2.900, 2.950, ?
2.850 - 2.800 = 50 O salto é +50.
2.950 + 50 = 3.000
3.000

## 6. Erro comum – cuidado!

Continue a sequência: 1.000, 1.100, 1.200, ?
1.100 - 1.000 = 100 O salto é +100.
Verifique: 1.200 − 1.100 = 100 – mesmo salto.
1.200 + 100 = 1.300
1.300
