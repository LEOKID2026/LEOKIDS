## 1. O que estamos aprendendo?

Hoje aprenderemos o que acontece quando você subtrai 0 de um número.
0 não “pega” nada – o número permanece o mesmo.

---

## 2. Explicação simples

Regra:
Qualquer número - 0 = o mesmo número.
789 − 0 = 789
3.200 - 0 = 3.200
Por quê? 0 significa "nada para tirar".
Se você tiver 789 coisas e tirar 0, você ainda terá 789.
Cuidado:
Isso é diferente de 789 − 789 (que é 0).
Aqui você subtrai 0, não o número em si.

5.640 - 0 = 5.640
