## 1. O que estamos aprendendo?

Nesta seção aprenderemos a somar três números — um após o outro ou em grupos amigáveis.
Por exemplo: 350 + 120 + 80.

---

## 2. Explicação simples

Maneiras de adicionar três números:
Um após o outro: (350 + 120) + 80
Par amigável primeiro: 350 + (120 + 80) — quando 120 + 80 = 200
Arredondamento: 398 + 102 + 50 → (398 + 102) + 50 = 500 + 50
Importante: some os três números – não pare depois dos dois!
350 + 120 + 80:
350 + 120 = 470
470 + 80 = 550

---

## 3. Exemplo visual/concreto

2.450 + 350 + 1.200
2.450 + 1.200 = 3.650 (os dois números maiores primeiro)
3.650 + 350 = 4.000
2.450 + 350 + 1.200 = 4.000

---

## 4. Vamos resolver juntos

Calcule: 820 + 180 + 500 =?
820 + 180 = 1.000 (par amigável — termina em 0).
1.000 + 500 = 1.500
820 + 180 + 500 = 1.500

## 6. Erro comum – cuidado!

Calcule: 450 + 120 + 80 =?
Procure um par amigável: 120 + 80 = 200
450 + 200 = 650
450 + 120 + 80 = 650
