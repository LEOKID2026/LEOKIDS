## 1. O que estamos aprendendo?

Hoje compararemos números grandes até 10.000 e escolheremos o símbolo certo: > (maior que), < (menor que), = (igual).

---

## 2. Explicação simples

Como comparamos grandes números?
Primeiros milhares – quem tem mais milhares?
Se igual – centenas
Se igual - dezenas
Se igual - uns
5.582 > 5.579 — milhares 5=5, centenas 5=5, dezenas 8>7 → 5.582 é maior
4.560 e 4.650:
milhares 4 = 4, centenas 5 < 6 → 4.560 < 4.650
O lado aberto do símbolo aponta para o número maior.

## 3. Exemplo visual/concreto

## 4. Vamos resolver juntos

Comparar: 5.307? 5.370
Milhares: 5 = 5 – igual, continue.
Centenas: 3 = 3 – igual, continue.
Dezenas: 0 <7.
5.307 < 5.370.
5.307 < 5.370
