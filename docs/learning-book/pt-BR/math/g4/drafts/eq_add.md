---

## 1. O que estamos aprendendo?

Hoje resolveremos equações de adição com números grandes — até 1.000.
Precisamos descobrir o que está faltando em __ para que a equação seja verdadeira.

---

## 2. Explicação simples

125 + __ = 380
Pergunte: o que você adiciona a 125 para chegar a 380?
380 − 125 = 255
125 + 255 = 380
Regra: número faltante = total (depois =) menos o número que você já possui.

---

## 3. Exemplo visual/concreto

240 + __ = 500
500 − 240 = 260
240 + 260 = 500

---

## 4. Vamos resolver juntos

318 + __ = 600 — qual é o número que falta?
600 − 318 = 282
Verifique: 318 + 282 = 600
O número que falta é 282.

## 6. Erro comum – cuidado!

180 + __ = 460 — qual é o número que falta?
Número faltante = total menos o número que você já possui.
460 − 180 = 280
Verifique: 180 + 280 = 460
O número que falta é 280
