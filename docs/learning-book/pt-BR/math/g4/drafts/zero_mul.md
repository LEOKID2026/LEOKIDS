## 1. O que estamos aprendendo?

Hoje aprenderemos o que acontece quando você multiplica um número por 0.
0 na multiplicação é especial — a resposta é sempre 0.

---

## 2. Explicação simples

Regra:
Qualquer número × 0 = 0.
52 × 0 = 0
0 × 347 = 0
Por quê?
Multiplicar por 0 significa “zero grupos” ou “zero vezes”.
Não há nada - a resposta é 0.
Mesmo um número grande × 0 = 0:
9.999 × 0 = 0

---

## 3. Exemplo visual/concreto

125 × 0 =?
125 × 0 = 0
0 grupos de 125 = nada = 0.
0 × 125 = 0 — mesmo quando 0 vem primeiro, a resposta é 0.
