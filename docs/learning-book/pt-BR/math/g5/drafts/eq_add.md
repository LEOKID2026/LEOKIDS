## 1. O que estamos aprendendo?

Hoje aprenderemos a resolver uma equação de adição com um espaço em branco — __.
Encontramos o número que falta.

---

## 2. Explicação simples

3.250 + __ = 8.400
Pergunte: o que você adiciona a 3.250 para chegar a 8.400?
__ = 8.400 - 3.250 = 5.150
Verifique: 3.250 + 5.150 = 8.400

---

## 3. Exemplo visual/concreto

__ = 9.500 - 4.200 = 5.300

## 4. Vamos resolver juntos

3.250 + __ = 8.400 — o que está faltando?
__ = 8.400 - 3.250
__ = 5.150
5.150.
