## 1. O que estamos aprendendo?

Hoje encontraremos vizinhos em números de até 100.000.
±1 funciona mesmo quando há zeros no meio — por exemplo 45.600.

---

## 2. Explicação simples

Vizinho antes = −1
Vizinho depois = +1
45.600:
- antes: 45.599
- depois: 45.601
Quando há zeros: 45.600 − 1 = 45.599 — não 45.500!
72.000 − 1 = 71.999 – ultrapassando mil.
Valor posicional: apenas os dígitos das unidades mudam em ±1 - mas cada dígito pode "rolar" para frente ou para trás.

---

## 3. Exemplo visual/concreto

72.000:
- antes: 71.999 (caímos mil — mas é apenas -1)
- depois: 72.001
45.599 → 45.600 → 45.601 — um zero no meio, mas ±1 ainda funciona normalmente.

---

## 4. Vamos resolver juntos

Quais são os vizinhos de 45.600?
Antes = 45.600 - 1 = 45.599
Depois = 45.600 + 1 = 45.601
Verifique: 45.599 + 1 = 45.600
45.599 e 45.601

## 6. Erro comum – cuidado!

Quais são os vizinhos de 82.000?
Antes = 82.000 − 1 = 81.999 (cruzando mil — todos os zeros se transformam em 9)
Depois = 82.000 + 1 = 82.001
Verifique: 81.999 + 1 = 82.000
Antes de 82.000: 81.999; depois: 82.001
