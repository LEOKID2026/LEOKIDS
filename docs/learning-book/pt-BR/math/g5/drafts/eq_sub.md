## 1. O que estamos aprendendo?

Hoje aprenderemos a resolver uma equação de subtração com um espaço em branco — __.
Precisamos encontrar o número que falta.

---

## 2. Explicação simples

__ − 1.875 = 4.200
Pergunte: de algum número você subtrai 1.875 e obtém 4.200 – qual é o número?
__ = 4.200 + 1.875 = 6.075
Verifique: 6.075 - 1.875 = 4.200

---

## 3. Exemplo visual/concreto

9.000 - __ = 3.500
__ = 9.000 - 3.500 = 5.500

---

## 4. Vamos resolver juntos

__ − 1.875 = 4.200 — o que está faltando?
__ = 4.200 + 1.875
__ = 6.075
6.075.

## 6. Erro comum – cuidado!

15.000 − __ = 6.500 — qual é o número que falta?
Pergunte: 15.000 menos quanto é igual a 6.500?
__ = 15.000 - 6.500 = 8.500
Verifique: 15.000 - 8.500 = 6.500
__ = 8.500
