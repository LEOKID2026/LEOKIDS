## 1. O que estamos aprendendo?

Hoje resolveremos equações de adição — um número faltante com números grandes.
2.450 +? = 4.030

---

## 2. Explicação simples

150.000 +? = 400.000 — número faltante adicional:
? = soma − número conhecido = 400.000 − 150.000
Regra: faltando = soma - conhecido - sem somar os dois números que você vê!

---

## 3. Exemplo visual/concreto

250.000 + __ = 500.000
__ = 500.000 - 250.000 = 250.000
Verifique: 250.000 + 250.000 = 500.000

---

## 4. Vamos resolver juntos

150.000 +? = 400.000
? = 400.000 - 150.000 = 250.000
Verifique: 150.000 + 250.000 = 400.000
250.000.

## 6. Erro comum – cuidado!

Resolva: 2.450 + ? = 4.030
? = soma − número conhecido = 4.030 − 2.450 = 1.580.
Verifique: 2.450 + 1.580 = 4.030
A resposta: ? = 1.580
