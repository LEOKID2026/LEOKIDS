## 1. O que estamos aprendendo?

Hoje aprenderemos a somar três números — até 200.000.
Você pode trabalhar da direita para a esquerda ou adicionar dois números primeiro.

---

## 2. Explicação simples

85.000 + 12.500 + 2.500 – três números grandes:
Caminho 1: (85.000 + 12.500) + 2.500 = 97.500 + 2.500 = 100.000
Caminho 2: 12.500 + 2.500 = 15.000; 85.000 + 15.000 = 100.000
Importante: some os três números – não pare depois dos dois!

---

## 3. Exemplo visual/concreto

62.000 + 18.500 + 9.500:
62.000 + 18.500 = 80.500
80.500 + 9.500 = 90.000

---

## 4. Vamos resolver juntos

45.000 + 27.500 + 7.500 =?
27.500 + 7.500 = 35.000 (um par conveniente).
45.000 + 35.000 = 80.000
80.000.

---

## 5. Experimente você mesmo

Calcule: 1.200 + 350 + 450 = ?
Tente resolver sozinho.
Na próxima página verificaremos os passos e a resposta juntos.

---

## 6. Erro comum – cuidado!

Calcule: 1.200 + 350 + 450
Escolha um par conveniente: 350 + 450 = 800
1.200 + 800 = 2.000
Verifique: todos os três números foram somados – 1.200, 350 e 450.
A resposta: 2.000

## 7. Vamos praticar!

A adição de três números aparece em problemas com palavras.
Na prática, você adicionará três números – escolha um par conveniente para adicionar primeiro!
