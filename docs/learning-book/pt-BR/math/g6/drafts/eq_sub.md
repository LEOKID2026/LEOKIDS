## 1. O que estamos aprendendo?

Hoje resolveremos equações de subtração — um número faltante com números grandes.
5.000 − ? = 3.725

---

## 2. Explicação simples

200.000 -? = 175.000 — número faltando no meio:
? = minuendo - resultado = 200.000 - 175.000
Regra: quando __ vem depois do sinal de menos - subtraia o resultado do minuendo.

---

## 3. Exemplo visual/concreto

350.000 - __ = 218.000
__ = 350.000 - 218.000 = 132.000
Verifique: 350.000 - 132.000 = 218.000

---

## 4. Vamos resolver juntos

200.000 -? = 175.000
? = 200.000 - 175.000 = 25.000
Verifique: 200.000 - 25.000 = 175.000
25.000.
