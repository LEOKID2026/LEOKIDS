## 1. O que estamos aprendendo?

Hoje vamos fortalecer a subtração de decimais.
5,80 - 2,35 — alinhe as casas decimais + empréstimo.

---

## 2. Explicação simples

5,80 - 2,35:
Alinhar: 5,80 - 2,35 = 3,45

---

## 3. Exemplo visual/concreto

10,00 - 3,45 = 6,55

---

## 4. Vamos resolver juntos

5,80 - 2,35 =?
0<5 → pedir emprestado. 10−5=5.
7−3=4, 5−2=3
3,45.

---

## 5. Experimente você mesmo

Calcule: 8,40 - 3,75 =?
Tente resolver sozinho.
Na próxima página verificaremos os passos e a resposta juntos.

---

## 6. Erro comum – cuidado!

Calcule: 8,40 - 3,75
Centésimos: 0<5 → emprestado dos décimos. 10−5=5.
Décimos: 3 (após empréstimo) < 7 → empréstimo de uns. 13−7=6.
Uns: 7 (após empréstimo) − 3 = 4.
Verifique: 4,65 + 3,75 = 8,40
A resposta: 4,65
