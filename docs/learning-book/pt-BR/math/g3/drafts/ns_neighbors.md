---

## 1. O que estamos aprendendo?

Hoje encontraremos números vizinhos — ±1 — mesmo quando cruzarmos uma fronteira de cem.
Por exemplo: 399 → 400 → 401 — cada passo é apenas 1.

---

## 2. Explicação simples

Vizinho antes = −1 (um passo para trás).
Vizinho depois = +1 (um passo à frente).
350:
- antes: 349
- depois: 351
Cruzando cem:
- 499 → depois = 500
- 500 → antes = 499
999 → depois = 1.000 (passamos para uma nova centena!)

---

## 3. Exemplo visual/concreto

628 na reta numérica:
628 − 1 = 627
628 + 1 = 629
399 → 400: o vizinho depois de 399 = 400 — limite de cem, mas ainda +1.
626 — 627 — [628] — 629 — 630

---

## 4. Vamos resolver juntos

Qual é o vizinho antes de 415? Qual é o vizinho depois de 415?
Antes = 415 − 1 = 414
Depois = 415 + 1 = 416
414 e 416
