**Escopo do conteúdo:** Adição com **ponto decimal** — um dígito após o ponto. Não há dois dígitos decimais.

---

## 1. O que estamos aprendendo?

Hoje aprenderemos a somar números decimais — com vírgula decimal (por exemplo 2,3 + 1,4).
Importante: alinhe as casas decimais – parte inteira sob parte inteira, décimos sob décimos.

---

## 2. Explicação simples

2,3 + 1,4
2 + 1 = 3 (inteiro)
0,3 + 0,4 = 0,7 (após o ponto)
2,3 + 1,4 = 3,7
Regra: adicione como se não houvesse ponto e depois coloque o ponto no mesmo lugar.

---

## 3. Exemplo visual/concreto

4,2 + 3,5
Inteiro: 4 + 3 = 7
Décimos: 2 + 5 = 7
4,2 + 3,5 = 7,7

---

## 4. Vamos resolver juntos

Calcule: 1,6 + 2,2 =?
Inteiro: 1 + 2 = 3
Décimos: 6 + 2 = 8 → 0,8
1,6 + 2,2 = 3,8

---

## 6. Erro comum – cuidado!

Calcular: 3,6 + 2,1
Inteiro: 3 + 2 = 5
Décimos: 6 + 1 = 7 → 0,7
3,6 + 2,1 = 5,7
