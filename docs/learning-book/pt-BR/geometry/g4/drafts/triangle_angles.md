## 1. O que estamos aprendendo?

Hoje em geometria aprenderemos uma regra importante: a soma dos ângulos de um triângulo = 180°.
Se você conhece dois ângulos, poderá encontrar o terceiro, faltando um.

---

## 2. Explicação simples

:::diagrama geométrico
tipo: ângulo_básico
:::

Em cada triângulo:
ângulo1 + ângulo2 + ângulo3 = 180°
Dois ângulos conhecidos?
Encontre o terceiro:
Ângulo faltante = 180° − (ângulo1 + ângulo2)
Primeiro some os dois ângulos conhecidos e depois subtraia de 180°.

---

## 3. Exemplo

Um triângulo com ângulos de 45° e 75°:
- 45° + 75° = 120°
- 180° - 120° = 60°
O terceiro ângulo: 60°.
Verifique: 45° + 75° + 60° = 180°

---

## 4. Vamos resolver juntos

Em um triângulo um ângulo mede 45° e outro mede 75°. Qual é o terceiro ângulo?
45° + 75° = 120°
180° - 120° = 60°
60°

## 6. Vamos verificar juntos

Em um triângulo: ângulo 60° e ângulo 80° — qual é o terceiro ângulo?
Adicione os dois ângulos conhecidos:
60° + 80° = 140°
Subtraia de 180°:
180° - 140° = 40°
O terceiro ângulo = 40°
