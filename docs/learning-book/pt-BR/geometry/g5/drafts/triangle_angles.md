## 1. O que estamos aprendendo?

Hoje exploraremos por que a soma dos ângulos em um triângulo é 180° — e usaremos isso para encontrar o ângulo que falta.
Idéia: se você “recortar” todos os três ângulos e colocá-los juntos — eles formam uma linha reta (180°).

---

## 2. Explicação simples

:::diagrama geométrico
tipo: ângulo_básico
:::

No triângulo ABC:
- ângulo A + ângulo B + ângulo C = 180°
Por quê? Os três ângulos juntos “preenchem” a abertura de uma linha reta – então a soma é sempre 180°.
Se você conhece A e B - encontre C:
C = 180° − (A + B)

---

## 3. Exemplo

No triângulo ABC: A = 60°, B = 70°
Raciocínio: 60° + 70° = 130° — “quanto falta” até 180°?
180° - 130° = 50° → C = 50°
Verifique: 60° + 70° + 50° = 180° — os três ângulos “fecham” uma linha reta.

---

## 4. Vamos resolver juntos

No triângulo ABC ângulo A = 60°, ângulo B = 70°. O que é o ângulo C?
Passo 1 (raciocínio): os dois ângulos juntos = 60° + 70° = 130°.
Etapa 2 (ausente): 180° − 130° = 50°
Etapa 3 (verificar): 60° + 70° + 50° = 180°
50°

## 6. Vamos verificar juntos

No triângulo ABC: ângulo A = 45°, ângulo B = 95° — o que é o ângulo C?
Adicione os dois ângulos conhecidos:
45° + 95° = 140°
Quanto resta de 180°?
180° - 140° = 40°
Verifique: 45° + 95° + 40° = 180°
Ângulo C = 40°

---

## 7. Vamos praticar!

A soma de 180° em um triângulo é uma regra com raciocínio – não apenas uma fórmula.
Na prática você encontrará um ângulo que falta — some, subtraia de 180° e verifique se a soma é 180°!
