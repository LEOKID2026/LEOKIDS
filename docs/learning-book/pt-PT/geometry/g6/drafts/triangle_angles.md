## 1. O que estamos aprendendo?

Hoje encontraremos um ângulo ausente em um triângulo passo a passo - com uma equação ex para o ângulo desconhecido.
Não apenas "180° menos adição" - mas: x + ângulo 1 + ângulo 2 = 180°.

---

## 2. Explicação simples

:::diagrama geométrico
tipo: ângulo_básico
:::

No triângulo ABC, rotulamos o ângulo ausente como x.
Equação: x + A + B = 180°
Etapas:
1.
Conecte os ângulos conhecidos
2.
Adiciona os conhecidos
3.
Resolve: x = 180° − (A + B)
4. Verifique: x + A + B = 180°

---

## 3. Exemplo

Em um triângulo: 55°, 65° e x (ausente).
Equação: x + 55° + 65° = 180°
Etapa a: 55° + 65° = 120°
Etapa b: x + 120° = 180°
Etapa c: x = 180° - 120° = 60°
Verifique: 60° + 55° + 65° = 180°

---

## 4. Vamos resolver juntos

No triângulo ABC ângulo A = 55°, ângulo B = 65°. Encontra o ângulo C - rotule-o como x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° - 120° = 60°
Passo 4 (verificar): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Experimenta mesmo

Em um triângulo: 40° e 65° — escreva a equação x + 40° + 65° = 180° e encontre x.
Tente resolver sozinho.
Na próxima página verificaremos os passos e a resposta juntos.

---

## 6. Vamos verificar juntos

Em um triângulo: ângulos 40° e 65° — encontre o terceiro ângulo x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° - 105° = 75°
Passo 4 (verificar): 75° + 40° + 65° = 180°
x = 75°

---

## 7. Vamos praticar!

Aqui encontramos um ângulo ausente com uma equação e uma verificação.
Na prática encontrará x +… = 180° — some os ângulos conhecidos, resolva x e verifique!
