## 1. O que estamos aprendendo?

Hoje resolveremos uma equação de adição — um problema com um número ausente (__).
Precisamos encontrar o que está faltando para que a equação seja verdadeira.

---

## 2. Explicação simples

45 + __ = 72
Pergunte: o que acrescentamos a 45 para chegar a 72?
72 − 45 = 27
45 + 27 = 72
Ou: pense — 45 + 20 = 65, mais mais 7 → 27.
O número que falta é 27 – não 72!

---

## 3. Exemplo visual/concreto

38 + __ = 65
65 − 38 = 27
38 + 27 = 65

---

## 4. Vamos resolver juntos

52 + __ = 80 — qual é o número que falta?
80 − 52 = 28
Verifique: 52 + 28 = 80
O número que falta é 28.
