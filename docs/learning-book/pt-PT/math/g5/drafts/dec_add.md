## 1. O que estamos aprendendo?

Hoje aprenderemos a somar números decimais com dois algarismos após a vírgula.
Importante:
Alinhe as casas decimais – centésimos sob centésimos, décimos sob décimos.

---

## 2. Explicação simples

12,45 + 3,60:
12h45
+ 3,60
———
Centésimos: 5+0=5
Décimos: 4+6=10→0, carregue 1
Inteiro: 12+3+1=16
12,45 + 3,60 = 16,05

---

## 3. Exemplo visual/concreto

5,28 + 2,14 = 7,42

## 4. Vamos resolver juntos

Calcula 12,45 + 3,60 =?
Centésimos 5+0=5
Décimos 4+6=10 → 0, carregue 1
Total 12+3+1=16
16.05

## 6. Erro comum – cuidado!

Calcula: 8,37 + 4,45 =?
Centésimos: 7 + 5 = 12 → 2, carregue 1
Décimos: 3 + 4 + 1 = 8
Inteiro: 8 + 4 = 12
8,37 + 4,45 = 12,82
