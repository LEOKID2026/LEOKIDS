## 1. O que estamos aprendendo?

Hoje aprenderemos a arredondar números inteiros para a dezena, centena, mil e dez mil mais próxima.
O arredondamento ajuda a estimar respostas em matemática e a fazer contas mentais rápidas.

---

## 2. Explicação simples

Etapas para arredondamento:
Observe o dígito à direita do local para o qual está arredondando
Se for 0, 1, 2, 3 ou 4 – arredonde para baixo (permaneça igual)
Se for 5, 6, 7, 8 ou 9 – arredonde (adicione 1)
Arredondando para a dezena mais próxima:
Olhe para aqueles
Arredondando para a centena mais próxima:
Olhe para as dezenas
Arredondando para o milhar mais próximo:
Olhe para as centenas
Arredondando para a dezena de milhar mais próxima:
Olhe para os milhares
38.750 elevado aos dez mil mais próximos:
Mil dígitos 8 → arredondamento → 40.000

---

## 3. Exemplo visual/concreto

38.750 elevado à dezena mais próxima:
- Dígito das unidades 0 → 38.750
38.750 aproximado ao milhar mais próximo:
- Centenas dígito 7 → arredondamento → 39.000
38.750 elevado aos dez mil mais próximos:
- Dígito 8 dos milhares → arredondamento → 40.000

---

## 4. Vamos resolver juntos

Arredonde 38.750 para o milhar mais próximo.
Algarismo das centenas: 7 → arredondar para cima.
38.750 → 39.000
39.000

## 6. Erro comum – cuidado!

Arredonde 46.380 para o milhar mais próximo.
Vê o algarismo das centenas: 3
3 < 5 → arredondar para baixo (ficar no milhar inferior)
46.380 → 46.000
46.380 ≈ 46.000
