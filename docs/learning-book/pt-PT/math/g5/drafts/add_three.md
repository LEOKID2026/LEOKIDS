## 1. O que estamos aprendendo?

Hoje aprenderemos a somar três números — até um total de cerca de 100.000.
Pode adicionar dois primeiro e depois o terceiro – passo a passo.

---

## 2. Explicação simples

Etapas:
Adiciona três números – primeiro dois, depois o terceiro
Trabalhe com aqueles - carregue quando precisar
Continua com dezenas, centenas, milhares, dez milhar
2.000 + 1.500 + 800:
2.000 + 1.500 = 3.500
3.500 + 800 = 4.300

---

## 3. Exemplo visual/concreto

12.000 + 8.500 + 3.200:
12.000 + 8.500 = 20.500
20.500 + 3.200 = 23.700

---

## 4. Vamos resolver juntos

Calcula 15.000 + 9.500 + 5.500 =?
9.500 + 5.500 = 15.000 (um par útil).
15.000 + 15.000 = 30.000
30.000.

## 5. Experimenta mesmo

## 6. Erro comum – cuidado!

Calcula: 5.000 + 3.500 + 1.200 =?
Adiciona dois primeiro: 5.000 + 3.500 = 8.500
Adiciona o terceiro: 8.500 + 1.200 = 9.700
5.000 + 3.500 + 1.200 = 9.700
