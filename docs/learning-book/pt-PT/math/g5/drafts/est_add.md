## 1. O que estamos aprendendo?

Hoje aprenderemos a estimar uma resposta de adição – não calcular exatamente, mas chegar perto.
≈ significa cerca de, perto de.

---

## 2. Explicação simples

3.487 + 2.512 ≈ ?
Arredonde para o milhar mais próximo:
3.487 ≈ 3.500
2.512 ≈ 2.500
3.500 + 2.500 = 6.000
3.487 + 2.512 ≈ 6.000

---

## 3. Exemplo visual/concreto

1.298 + 4.703 ≈ ?
1.298 ≈ 1.300; 4.703 ≈ 4.700
1.300 + 4.700 = 6.000

---

## 4. Vamos resolver juntos

3.487 + 2.512 ≈ ?
3.487 ≈ 3.500; 2.512 ≈ 2.500
3.500 + 2.500 = 6.000
≈ 6.000

---

## 6. Erro comum – cuidado!

6.250 + 2.730 ≈ ?

6.000 + 3.000 = 9.000
