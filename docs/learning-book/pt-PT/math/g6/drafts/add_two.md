## 1. O que estamos aprendendo?

Hoje aprenderemos a somar dois números até 200.000.
Trabalhe de unidades → dezenas → centenas → milhares → dez milhares → centenas de milhares, com transporte.

---

## 2. Explicação simples

12.450 + 3.875:
- uns: 0+5=5
- dezenas: 5+7=12 → 2, carregue 1
- centenas: 4+8+1=13 → 3, carregue 1
- milhares: 2+3+1=6
- dez mil: 1+0=1
= 16.325

---

## 3. Exemplo visual/concreto

48.750 + 25.680 = 74.430
Verifique: 74.430 - 25.680 = 48.750

---

## 4. Vamos resolver juntos

Calcula 48.750 + 25.680 =?
Uns: 0 + 0 = 0
Dezenas: 5 + 8 = 13 → escreva 3, carregue 1
Centenas: 7 + 6 + 1 = 14 → escreva 4, carregue 1
Milhares: 8 + 5 + 1 = 14 → escreva 4, carregue 1
Dez mil: 4 + 2 + 1 = 7
48.750 + 25.680 = 74.430

## 6. Erro comum – cuidado!

Calcula: 34.267 + 15.486
Uns: 7+6=13 → 3, carregue 1.
Dezenas: 6+8+1=15 → 5, carregue 1.
Centenas: 2+4+1=7
Milhares: 4+5=9
Dez mil: 3+1=4
A resposta: 49.753
