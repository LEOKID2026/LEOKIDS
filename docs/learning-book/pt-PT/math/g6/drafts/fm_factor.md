## 1. O que estamos aprendendo?

Hoje vamos fortalecer os fatores — números que se multiplicam para dar um determinado resultado.
36 = 1×36 = 2×18 = 3×12 = 4×9 = 6×6

---

## 2. Explicação simples

Fatores de 36: 1, 2, 3, 4, 6, 9, 12, 18, 36
Verifique de 1 até √36 = 6.

---

## 3. Exemplo visual/concreto

24: 1, 2, 3, 4, 6, 8, 12, 24

## 4. Vamos resolver juntos

Liste todos os fatores de 36.
1×36, 2×18, 3×12, 4×9, 6×6.
1, 2, 3, 4, 6, 9, 12, 18, 36.
