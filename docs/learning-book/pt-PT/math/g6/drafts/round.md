## 1. O que estamos aprendendo?

Hoje aprenderemos a arredondar números inteiros – para a dezena, centena ou milhar mais próximo.
Observe o dígito à direita do local para o qual está arredondando.

---

## 2. Explicação simples

Arredondando para o milhar mais próximo – observe o algarismo das centenas.
47.832 → arredondar para o milhar mais próximo:
- centenas = 8 (≥ 5) → arredondar
- 47.832 ≈ 48.000

---

## 3. Exemplo visual/concreto

1.247 elevado à dezena mais próxima:
- unidades = 7 (≥ 5) → 1.250
1.247 elevado à centena mais próxima:
- dezenas = 4 (< 5) → 1.200

---

## 4. Vamos resolver juntos

Arredonde 47.832 para o milhar mais próximo.
O algarismo das centenas = 8.
8 ≥ 5 → arredondar.
48.000.

---

## 5. Experimenta mesmo

Arredonde 63.417 para o milhar mais próximo.
Tente resolver sozinho.
Na próxima página verificaremos os passos e a resposta juntos.

---

## 6. Erro comum – cuidado!

Arredonde 63.417 para o milhar mais próximo
Observe o algarismo das centenas: 4.
4 < 5 → arredondar para baixo.
Milhares ficam 3, centenas e abaixo tornam-se zero.
A resposta: 63.000
