## 1. O que estamos aprendendo?

Hoje resolveremos equações de subtração com um número ausente — por exemplo __ − 45 = 120.
Precisamos de determinar o número maior — aquele ao qual subtraímos.

---

## 2. Explicação simples

__ − 45 = 120
Pergunte: de algum número subtraímos 45 e obtivemos 120 — qual é o número?
120 + 45 = 165
165 − 45 = 120
Regra: número que falta antes do menos = resultado + o número que está sendo subtraído.

---

## 3. Exemplo visual/concreto

__ − 72 = 208
208 + 72 = 280
280 − 72 = 208

---

## 4. Vamos resolver juntos

__ − 38 = 142 — qual é o número que falta?
142 + 38 = 180
180 − 38 = 142
O número que falta é 180.

## 6. Erro comum – cuidado!

__ − 63 = 175 — qual é o número que falta?
Número faltante antes do sinal de menos — some o resultado e o número que está sendo subtraído.
175 + 63 = 238
Verifique: 238 − 63 = 175
O número que falta é 238
