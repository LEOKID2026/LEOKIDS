**Escopo do conteúdo:** Adicionando 0 a um número. A propriedade de identidade da adição. Sem pontos negativos.

---

## 1. O que estamos aprendendo?

Hoje aprenderemos o que acontece quando adiciona 0 a um número.
0 é um número especial – além disso, não altera a resposta.

---

## 2. Explicação simples

Regra:
Qualquer número + 0 = o mesmo número.
0 não acrescenta nada – o número permanece o mesmo.
456 + 0 = 456
0 + 789 = 789
Por quê? 0 significa "nada a acrescentar".
Se tiver 456 coisas e adicionar 0, ainda terá 456.
Mesmo com números grandes – a regra é a mesma.

---

## 3. Exemplo visual/concreto

2.350 + 0 =?
2.350 + 0 = 2.350
0 + 2.350 = 2.350
Em ambos os casos a resposta é a mesma – 2.350.

---

## 4. Vamos resolver juntos

Calcula: 1.008 + 0 =?
Adicionando 0 – nada muda.
1.008 + 0 = 1.008
1.008
