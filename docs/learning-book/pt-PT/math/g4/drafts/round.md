## 1. O que estamos aprendendo?

Hoje aprenderemos a arredondar um número para a dezena, centena ou milhar mais próximo.
O arredondamento ajuda a estimar respostas e fazer contas mentais rápidas.

---

## 2. Explicação simples

Etapas para arredondamento:
Observe o dígito à direita do local para o qual está arredondando
Se for 0, 1, 2, 3 ou 4 – arredonde para baixo (permaneça igual)
Se for 5, 6, 7, 8 ou 9 – arredonde (adicione 1)
Arredondando para dezenas:
Olhe para os dígitos das unidades
Arredondando para centenas:
Observe o algarismo das dezenas
Arredondando para milhares:
Olhe para o algarismo das centenas
3.847 elevado à dezena mais próxima:
Dígito 7 das unidades → arredondar para cima → 3.850

---

## 3. Exemplo visual/concreto

2.635 elevado à dezena mais próxima:
Dígito das unidades: 5 → arredondar
2.635 → 2.640
2.635 elevado à centena mais próxima:
Dígito das dezenas: 3 → arredondar para baixo
2.635 → 2.600

---

## 4. Vamos resolver juntos

Arredonde 4.582 para a dezena mais próxima.
Algarismo das unidades: 2 → arredondar para baixo.
4.582 → 4.580
4.580

## 6. Erro comum – cuidado!

Arredonde 1.247 para a centena mais próxima.
Arredondando para centenas – observe o algarismo das dezenas.
O algarismo das dezenas em 1.247 é 4 (4 <5 → arredondado para baixo).
1.247 → 1.200
1.200
