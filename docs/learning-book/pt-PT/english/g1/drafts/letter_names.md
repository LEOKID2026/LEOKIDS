## 1. O que estamos aprendendo?

Hoje aprenderemos os nomes das letras em inglês.
Há uma diferença entre o nome de uma letra e o som que a letra produz em uma palavra – aprenderemos ambos mais tarde.

---

## 2. Explicação simples

Quando falamos de cartas, há duas coisas diferentes:
O nome da carta — como chamamos a carta.
O som de uma palavra – o som que a letra faz dentro de uma palavra.
Vamos conhecer as três primeiras letras:
A é a primeira letra.
B é a segunda letra.
C é a terceira letra.
Na palavra gato, a letra C emite o som “k”.
Esse é o som da palavra e é diferente do nome da letra.

---

## 3. Exemplo

Praticamos o reconhecimento de letras ouvindo.
Quando ouvimos o nome da letra A – procuramos por A.
Quando ouvimos o nome da letra M — procuramos por M.
Ouvimos o nome da letra e apontamos para a forma correta.
