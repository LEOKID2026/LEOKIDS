## 1. O que estamos aprendendo?

Hoje aprenderemos qual é o primeiro som de uma palavra em inglês.
Ouvimos uma palavra – e encontramos o som que a inicia.

---

## 2. Explicação simples

A palavra gato começa com um som “k”.
A palavra cão começa com um som “d”.
A palavra sol começa com o som de “s”.
Ainda não estamos escrevendo – apenas ouvindo.

---

## 3. Exemplo

Na palavra mãe, ouvimos um som “m” no início.
A palavra mãe começa com o som de “m”.
Na palavra caneta, ouvimos um som “p” no início.
A palavra caneta começa com um som “p”.

---

## 4. Vamos resolver juntos

Qual é o primeiro som do gato?
Diga devagar: gato.
A palavra gato começa com um som “k”.
k

---

## 5. Experimenta mesmo

Qual é o primeiro som do chapéu?
Tente resolver mesmo.

## 6. Vamos verificar juntos

Qual é o primeiro som do chapéu?
Diga devagar: chapéu.
A palavra chapéu começa com um som de “h”.
O primeiro som do chapéu é "h".
