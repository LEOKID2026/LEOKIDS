## 1. O que estamos aprendendo?

Hoje aprenderemos letras maiúsculas em inglês – A, B, C, até Z.
Uma letra maiúscula é um formato especial de letra. Em inglês, letras maiúsculas são usadas no início das frases e nos nomes. Aqui, primeiro conheceremos sua forma.
Este é o primeiro passo para ler em inglês.

---

## 2. Explicação simples

O inglês tem 26 letras.
Iremos encontrá-los lentamente, em pequenos grupos.
Vamos começar com as três primeiras letras:
A é a primeira letra.
B é a segunda letra.
C é a terceira letra.
Em cada página reconheceremos o formato da letra e ouviremos seu nome.

---

## 3. Exemplo

Vamos conhecer duas letras maiúsculas: B e M.
B é uma letra.
M é outra letra.
Reconhecemos cada letra pela sua forma.

---

## 4. Vamos resolver juntos

Que letra maiúscula é essa?
K
K tem uma linha reta e duas linhas inclinadas que se encontram no meio.
Esta é a letra K.
K
