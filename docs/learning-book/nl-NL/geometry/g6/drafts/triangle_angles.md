## 1. Wat gaan we leren?

Vandaag zullen we find a missing angle in een driehoek step by step — with an equation and x for the unknown angle.
Not just "180° minus addition" — but: x + angle 1 + angle 2 = 180°.

---

## 3. Voorbeeld

In een driehoek: 55°, 65°, and x (missing).
Equation: x + 55° + 65° = 180°
Step a: 55° + 65° = 120°
Step b: x + 120° = 180°
Step c: x = 180° − 120° = 60°
Check: 60° + 55° + 65° = 180°

---

## 4. Laten we het samen oplossen

In triangle ABC angle A = 55°, angle B = 65°. Find angle C — label it x.
x + 55° + 65° = 180°
55° + 65° = 120° → x + 120° = 180°
x = 180° − 120° = 60°
Step 4 (check): 60° + 55° + 65° = 180°
C = 60° (x = 60°)

---

## 5. Probeer het zelf

In een driehoek: 40° en 65° — schrijf de vergelijking x + 40° + 65° = 180° en vind x.
Try to solve by yourself.
Op de volgende pagina kijken we samen de stappen en het antwoord na.

## 6. Laten we samen nakijken

In een driehoek: angles 40° and 65° — find the third angle x.
x + 40° + 65° = 180°
40° + 65° = 105° → x + 105° = 180°
x = 180° − 105° = 75°
Step 4 (check): 75° + 40° + 65° = 180°
x = 75°
