## 1. Wat gaan we leren?

Vandaag leren we the area of a parallelogram.
Area = base × height.
The height — the perpendicular distance to the base (not the slanted side!).

---

## 2. Eenvoudige uitleg

:::geometry-diagram
type: parallelogram_area
:::

In a parallelogram:
- base — the side we choose (for example 8 cm)
- height — the perpendicular segment from the base to the parallel side (5 cm)
Area = base × height
Don't use the slanted side — only the height.

---

## 3. Voorbeeld

Base 8 cm, height 5 cm:
8 × 5 = 40 cm²

---

## 4. Laten we het samen oplossen

Parallelogram — base 8 cm, height 5 cm. Wat is the area?

## 6. Laten we samen nakijken

Parallelogram: base 6 cm, height 7 cm — wat is the area?
Multiply base by the perpendicular height:
6 × 7 = 42
Area = 42 cm²
