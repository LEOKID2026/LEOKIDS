## 1. Wat gaan we leren?

Vandaag bij natuur en techniek leren we how to investigate like scientists — with observation, comparison, and one variable.

---

## 2. Eenvoudige uitleg

Scientific investigation starts simply:
Observation — we look and describe (wat is happening?)
Comparison — we compare two situations (wat is different?)
One variable — change only one thing; everything else stays the same (a fair test)
Safe example:
Two identical pots — one gets light, one gets darkness.
Only the light changes — everything else is the same.
With a teacher only.
No fire, no chemicals, no electricity.

---

## 3. Voorbeeld

Groeit een plant bij het raam hoger?
Observation:
Measure the height every day.
Comparison:
Pot by the window versus pot in a dark corner.
Variable:
Location (light).
Same:
Same amount of water, same pot, same seed.
Schrijf op wat je ziet — zonder te raden.

---

## 4. Laten we het samen oplossen

Why change only one thing in a test?
Als je zowel water als licht verandert — weet je niet wat het verschil maakte.
One variable — a clear result.
Zo weten we wat de verandering veroorzaakte

## 6. Laten we samen nakijken

The question was:
Wat is de variabele in een test van een plant bij een raam versus een plant in een donkere hoek?
In a fair test you change only one thing — that is the variable.
Here:
The location (by a window with light versus a dark corner) is the only thing that changes.
Everything else stays the same:
Same pot, same water, same seed.
The answer: the variable is the amount of light (the plant's location).
