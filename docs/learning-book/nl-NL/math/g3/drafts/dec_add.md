**Inhoudsbereik:** Addition with **decimal point** — one digit after the point. No two decimal digits.

---

## 1. Wat gaan we leren?

Vandaag leren we add decimal numbers — with a decimal point (for example 2.3 + 1.4).
Important: line up the decimal points — whole part under whole part, tenths under tenths.

---

## 2. Eenvoudige uitleg

2.3 + 1.4
2 + 1 = 3 (whole)
0.3 + 0.4 = 0.7 (after the point)
2.3 + 1.4 = 3.7
Rule: add as if there's no point, then put the point in the same place.

---

## 3. Visueel / concreet voorbeeld

4.2 + 3.5
Whole: 4 + 3 = 7
Tenths: 2 + 5 = 7
4.2 + 3.5 = 7.7

---

## 4. Laten we het samen oplossen

Calculate: 1.6 + 2.2 = ?
Whole: 1 + 2 = 3
Tenths: 6 + 2 = 8 → 0.8
1.6 + 2.2 = 3.8
