## 1. Wat gaan we leren?

Vandaag zullen we solve an addition equation — a problem with a ontbrekende getal (__).
We need to find what's missing so the equation is true.

---

## 2. Eenvoudige uitleg

45 + __ = 72
Vraag: wat tellen we bij 45 op om op 72 te komen?
72 − 45 = 27
45 + 27 = 72
Or: think — 45 + 20 = 65, plus 7 more → 27.
The ontbrekende getal is 27 — not 72!

---

## 3. Visueel / concreet voorbeeld

38 + __ = 65
65 − 38 = 27
38 + 27 = 65

---

## 4. Laten we het samen oplossen

52 + __ = 80 — wat is het ontbrekende getal?
80 − 52 = 28
Check: 52 + 28 = 80
The ontbrekende getal is 28.
