## 1. Wat gaan we leren?

Vandaag gaan we hoeveel days pass from one day to another on the row of days.
Count hops — without counting the start day as the first step.

---

## 2. Eenvoudige uitleg

Hoeveel days from day X to day Y?
→ Count hops after the start day, up to the target day.
Before you answer:
1. Wat weten we? — which day we start on and which day we reach
2. Wat wordt gevraagd? — hoeveel days pass
3. Wat doen we? — tel sprongen op de rij
Important: don't count the start day. No clock or dates in the month.
