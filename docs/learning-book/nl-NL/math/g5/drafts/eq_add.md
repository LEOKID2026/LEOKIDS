## 1. Wat gaan we leren?

Vandaag leren we to solve an addition equation with a blank — __.
We find the ontbrekende getal.

---

## 2. Eenvoudige uitleg

3,250 + __ = 8,400
Vraag: wat tel je bij 3.250 op om op 8.400 te komen?
__ = 8,400 − 3,250 = 5,150
Check: 3,250 + 5,150 = 8,400

---

## 3. Visueel / concreet voorbeeld

__ + 4,200 = 9,500
__ = 9,500 − 4,200 = 5,300

---

## 4. Laten we het samen oplossen

3,250 + __ = 8,400 — wat is missing?
__ = 8,400 − 3,250
__ = 5,150
5,150.

---

## 5. Probeer het zelf

Probeer het zelf op te lossen.

## 6. Veelgemaakte fout — let op!

__ + 5,300 = 12,700 — wat is het ontbrekende getal?
__ = 12,700 − 5,300
__ = 7,400
Check: 7,400 + 5,300 = 12,700
__ = 7,400
