**Inhoudsbereik:** **Estimate** (≈) of an addition sum — round to nearest hundreds/tens. No exact calculation required. No rounding to ten-thousands.

---

## 1. Wat gaan we leren?

Vandaag leren we to estimate an addition answer — not exact, but about right.
≈ means about, close to.

---

## 2. Eenvoudige uitleg

487 + 512 ≈ ?
Round each number to a friendly number (for example to the nearest hundred):
487 ≈ 500
512 ≈ 500
500 + 500 = 1,000
487 + 512 ≈ 1,000
Why? 487 is close to 500, 512 is close to 500 — and the sum is about 1,000.
Estimating helps you check if an exact answer makes sense.

---

## 3. Visueel / concreet voorbeeld

298 + 403 ≈ ?
298 ≈ 300
403 ≈ 400
300 + 400 = 700
298 + 403 ≈ 700
(Exactly: 701 — very close!)

---

## 4. Laten we het samen oplossen

356 + 241 ≈ ?
356 ≈ 360 (or 400).
241 ≈ 240 (or 200).
360 + 240 = 600 (or 400 + 200 = 600).
356 + 241 ≈ 600

## 6. Veelgemaakte fout — let op!

623 + 382 ≈ ?
Round: 623 ≈ 600.
Round: 382 ≈ 400.
600 + 400 = 1,000
623 + 382 ≈ 1,000
