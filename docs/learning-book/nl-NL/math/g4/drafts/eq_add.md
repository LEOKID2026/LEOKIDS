**Inhoudsbereik:** Addition equation with **__** — numbers up to **1,000**. Reverse subtraction to find the ontbrekende getal. No variable x.

---

## 1. Wat gaan we leren?

Vandaag zullen we solve addition equations with grote getallen — up to 1,000.
We need to find what's missing in __ so the equation is true.

---

## 2. Eenvoudige uitleg

125 + __ = 380
Vraag: wat tel je bij 125 op om op 380 te komen?
380 − 125 = 255
125 + 255 = 380
Rule: ontbrekende getal = total (after =) minus the number you already have.

---

## 3. Visueel / concreet voorbeeld

240 + __ = 500
500 − 240 = 260
240 + 260 = 500

---

## 4. Laten we het samen oplossen

318 + __ = 600 — wat is het ontbrekende getal?
600 − 318 = 282
Check: 318 + 282 = 600
The ontbrekende getal is 282.

---

## 5. Probeer het zelf

Probeer het zelf op te lossen.

## 6. Veelgemaakte fout — let op!

180 + __ = 460 — wat is het ontbrekende getal?
Ontbrekend getal = totaal minus het getal dat je al hebt.
460 − 180 = 280
Check: 180 + 280 = 460
The ontbrekende getal is 280
