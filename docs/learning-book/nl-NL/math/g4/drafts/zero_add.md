**Inhoudsbereik:** Adding 0 to a number. The identity property of addition. No negatives.

---

## 1. Wat gaan we leren?

Vandaag leren we wat er gebeurt als je 0 bij een getal optelt.
0 is a special number — it doesn't change the answer in addition.

---

## 2. Eenvoudige uitleg

Rule:
Any number + 0 = the same number.
0 doesn't add anything — the number stays the same.
456 + 0 = 456
0 + 789 = 789
Why? 0 means "nothing to add."
If you have 456 things and add 0 — you still have 456.
Ook bij grote getallen — de regel is hetzelfde.

---

## 3. Visueel / concreet voorbeeld

2,350 + 0 = ?
2,350 + 0 = 2,350
0 + 2,350 = 2,350
In both cases the answer is the same — 2,350.

---

## 4. Laten we het samen oplossen

Work out: 1,008 + 0 = ?
Adding 0 — nothing changes.
1,008 + 0 = 1,008
