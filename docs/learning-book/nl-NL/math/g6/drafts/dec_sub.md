## 1. Wat gaan we leren?

## 2. Eenvoudige uitleg

Align: 5.80 − 2.35 = 3.45

## 3. Visueel / concreet voorbeeld

10.00 − 3.45 = 6.55

5.80 − 2.35 = ?

7−3=4, 5−2=3

## 6. Veelgemaakte fout — let op!

Calculate: 8.40 − 3.75
Hundredths: 0<5 → borrow from tenths. 10−5=5.
Tenths: 3 (after borrowing) < 7 → borrow from ones. 13−7=6.
Ones: 7 (after borrowing) − 3 = 4.
Check: 4.65 + 3.75 = 8.40
The answer: 4.65
